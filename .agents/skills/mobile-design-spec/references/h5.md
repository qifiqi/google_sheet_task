# H5 页面设计规范

## 1. 自适应单位方案

- **rem**：相对于根元素（html）font-size 的单位，H5 自适应布局主流方案
- **vw / vh**：视口宽度 / 高度的 1%

**rem + flexible.js（手淘方案）**：
- 设计稿 750px：根字号设 75px，即 **1rem = 75px**
- 换算：`rem = 设计稿尺寸(px) ÷ 75`（750 稿）或 `÷ 37.5`（375 稿）

**vw 方案**：1vw = 屏幕宽度的 1%；设计稿 750px 时 **1px ≈ 0.1333vw**

## 2. 基础尺寸

- **设计基准**：750×1334px（@2x），所有标注以 @2x 为准
- **页面左右边距**：30px（@2x，即逻辑 15px）
- **正文字号**：28px（@2x，即逻辑 14px）
- **行高**：1.5 倍字号
- **安全区域**：需兼容 iPhone X 及以上底部安全区，使用：
  ```css
  padding-bottom: env(safe-area-inset-bottom);
  /* 兼容旧版本：constant(safe-area-inset-bottom) */
  ```

## 3. 字体规范

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI',
             Roboto, 'Helvetica Neue', Arial, sans-serif;
```

字号建议（@2x）：

| 层级 | 字号 |
|---|---|
| 大标题 | 36px |
| 标题 | 32px |
| 小标题 | 30px |
| 正文 | 28px |
| 辅助说明 | 24px |

## 4. 颜色与交互

- **链接色**：`#576B95`（微信内）或品牌色
- **主按钮**：高度 88px（@2x，即逻辑 44px），最小宽度 160px（@2x）
- **次按钮**：高度 72px（@2x，即逻辑 36px）
- **点击态**：透明度降至 0.7 或颜色加深 10%
- **禁用态**：opacity 0.4
- **图片圆角**：8px（@2x，即逻辑 4px）
- **卡片圆角**：16px（@2x，即逻辑 8px）
- **分割线**：1px，`rgba(0,0,0,0.1)`

## 5. 交互与适配注意事项

- **1px 边框问题**：高倍屏下 CSS 的 1px 实际渲染为 2-3 物理像素，视觉偏粗。解决：伪元素 + `transform: scaleY(0.5)`，或 border-image / box-shadow 细化
- **图片适配**：`width: 100%` + `height: auto`，避免固定高度；大图用懒加载
- **横竖屏**：如需支持横屏，单独设计或用媒体查询适配
- **加载体验**：首屏加载超过 3 秒流失率大增，首屏用骨架屏 + 渐进加载；超过 3 秒需有进度提示

## 6. 响应式断点

| 设备 | 断点 |
|---|---|
| 手机 | < 768px |
| 平板 | 768 - 1024px |
| 桌面 | > 1024px |
