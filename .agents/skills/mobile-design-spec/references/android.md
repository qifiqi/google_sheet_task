# Android 设计规范（碎片化时代的生存指南）

## 1. 基础单位

- **dp**（density-independent pixel）：密度无关像素，Android 基础尺寸单位
- **sp**（scale-independent pixel）：主要用于文字，随系统字体设置缩放
- **px**：物理像素
- **换算关系**：`px = dp × (dpi ÷ 160)`

## 2. 屏幕密度分级

| 密度 | 倍率 | 1dp = |
|---|---|---|
| ldpi | 0.75x | 0.75px |
| mdpi（基准） | 1x | 1px |
| hdpi | 1.5x | 1.5px |
| xhdpi | 2x | 2px |
| xxhdpi | 3x | 3px |
| xxxhdpi | 4x | 4px |

切图需导出 mdpi~xxxhdpi 全套资源。

## 3. 字体规范

系统字体：**Roboto**（中文 Noto Sans SC / 思源黑体）。

| 层级 | 字号 |
|---|---|
| 大标题 | 20sp |
| 标题 | 17sp |
| 正文（基准） | 14sp |
| 辅助说明 | 12sp |

行高建议 1.2-1.5 倍。

## 4. 颜色规范（Material Design）

- **主色**：`#6200EE`（Material 紫）
- **辅助色**：`#03DAC6`（青）

| 语义 | 色值 |
|---|---|
| 错误红 | `#B00020` |
| 成功绿 | `#388E3C` |
| 警告橙 | `#FF9800` |
| 信息蓝 | `#2196F3` |

**深色模式**：需提供深浅两套色板。主要文字浅色模式 `#000000`（87% 透明度），深色模式 `#FFFFFF`（87%）。

## 5. 布局规范

- **基准设计尺寸**：360×640dp（小屏）或 360×800dp（现代全面屏）
- **页面左右边距**：16dp
- **组件间距**：8dp 基准网格（8dp Grid），所有间距取 8 的倍数
- **最小可点击区域**：48×48dp（Material Design 推荐）
- **底部导航栏**：56dp + 手势导航条避让
- **顶部应用栏（AppBar）**：56dp，滚动时可选用 128dp 大标题模式

⚠️ Android 千万别用 iPhone 的 375 宽度做设计稿：dp 与 pt 数值体系不同，会导致布局错位。

## 6. 图标规范

- **App 图标**：512×512px；自适应图标（Adaptive Icon）前景层 108dp，其中安全区域 66dp
- **标签栏图标**：24×24dp
- **通知栏图标**：纯白色，带透明度
