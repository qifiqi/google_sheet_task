# 微信小程序设计规范

## 1. 基础单位 rpx

- **rpx**（responsive pixel）是微信小程序独有的响应式单位
- **屏幕宽度统一为 750rpx**，任何机型上都成立
- 在 iPhone 6 上：1rpx = 0.5px = 1 物理像素
- **换算公式**（以 375px 宽屏幕为基准）：
  - `rpx = px × 2`
  - `px = rpx ÷ 2`
- **设计稿建议**：直接用 **750×1334**（iPhone 8，@2x）做设计稿，此时设计稿中 1px = 1rpx，标注即所得

## 2. 常用组件尺寸

- **导航栏**：微信 7.0+ 右上角**胶囊按钮**高 32px、宽 87px，自定义导航栏时必须避让该区域，避免与页面按钮冲突
- **标签栏（TabBar）**：高度 56px（含边框），图标 24-28px，文字 10px

## 3. 字体规范

系统字体：`-apple-system`（iOS）/ Roboto（Android），跟随微信默认字体。

| 层级 | 字号 |
|---|---|
| 页面大标题 | 17px（加粗） |
| 标题 | 17px |
| 正文（重要） | 15px |
| 正文（次要） | 14px |
| 辅助说明 | 12px |
| 警示文字 | 12px |

## 4. 颜色规范

- **微信品牌绿**：`#07C160`
- **链接色**：`#576B95`（微信内链蓝灰色）
- **文字颜色**（黑色系按透明度分级）：
  - 主要文字：`rgba(0,0,0,0.85)`
  - 次要文字：`rgba(0,0,0,0.55)`
  - 辅助/占位：`rgba(0,0,0,0.35)`

## 5. WeUI 组件库

WeUI 是微信官方组件库、小程序 UI 的事实标准，建议直接使用其色板和组件尺寸。

**WeUI 色板**：

| 色名 | 色值 |
|---|---|
| 主色（品牌绿）/ 成功绿 | `#07C160` |
| 辅助蓝 | `#10AEFF` |
| 警示红 | `#FA5151` |
| 辅助橙 | `#FA9D3B` |
| 辅助黄 | `#FFC300` |
| 链接蓝灰 | `#576B95` |

**WeUI 常用组件尺寸**：

| 组件 | 尺寸 |
|---|---|
| 按钮高度 | 大 48px / 默认 44px / 迷你 32px（上下 padding 分别 16 / 12 / 8px） |
| Cell 单元格高度 | ≥ 56px |
| 复选/单选图标 | 22×22px |
| 对话框圆角 | 8px |
| Toast | 宽度自适应，最长约 60% 屏宽，圆角 8px |
