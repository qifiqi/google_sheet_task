**设计基准**：以 375×812 为基准设计，向上向下自适应。

## 2. 安全区域（Safe Area）

- **状态栏**：iPhone X 及之后机型 **44pt**（刘海/灵动岛屏）；之前机型 20pt
- **底部 Home Indicator 区域**：**34pt**
- 内容不要伸进这两个区域；滚动内容可以延伸到底部，但固定按钮需上移 34pt

## 3. 字体规范

系统字体：**SF Pro Text**（中文为苹方 PingFang SC）。

| 层级 | 字号 |
|---|---|
| 大标题（导航大标题） | 34pt |
| 标题一 | 22pt |
| 标题二 | 17pt 加粗 |
| 正文 | 17pt |
| 脚注 | 13pt |
| 说明文字 | 12pt |

## 4. 颜色规范

**主色调**：系统蓝 `#007AFF`

| 颜色 | 色值 | 颜色 | 色值 |
|---|---|---|---|
| 红 red | `#FF3B30` | 紫 purple | `#AF52DE` |
| 橙 orange | `#FF9500` | 粉 pink | `#FF2D55` |
| 黄 yellow | `#FFCC00` | 青 teal | `#30B0C7` |
| 绿 green | `#34C759` | 靛蓝 indigo | `#5856D6` |
| 蓝 blue | `#007AFF` | 薄荷 mint | `#00C7BE` |
| 灰 gray | `#8E8E93` | 浅灰 | `#636366` |
| cyan | `#32ADE6` | 深灰多级 | `#48484A` / `#3A3A3C` / `#2C2C2E` |

## 5. 圆角与间距

- **卡片圆角**：8pt
- **按钮圆角**：连续圆角（Continuous Corner）；小按钮 8pt，大按钮 12-16pt
- **页面左右边距**：16pt
- **卡片间距**：8pt
- **列表最小行高**：44pt（Apple HIG 推荐最小可点击区域 44×44pt）

## 6. 图标规范

- **App 图标**：1024×1024px，圆角由系统自动处理（**不要手动切圆角**）
- **标签栏图标**：24×24pt（@3x 下为 72×72px）
- **导航栏图标**：约 22×22pt

## 7. 切图导出

iOS 需导出 @1x / @2x / @3x 三套切图，命名如 `icon_home@3x.png`。
