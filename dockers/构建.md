我来帮你完成这个任务。首先构建镜像，然后导出为离线tar包，最后在生产环境导入运行。

## 1. 构建Docker镜像

```bash
docker run -d --name mysql-container -e MYSQL_ROOT_PASSWORD=Hello1234* -p 3306:3306 -v mysql-data:/var/lib/mysql -e MYSQL_DATABASE=googlesheet_validator  --restart=always mysql:5.7

docker build -t google_task:1.0.7 .
```

## 2. 导出为离线tar包

```bash
# 导出镜像为tar文件
docker save -o google_task_1.0.7.tar google_task:1.0.7

# 或者使用更明确的路径
docker save google_task:1.0.5 > google_task_1.0.5.tar
```

## 3. 压缩tar包（可选，方便传输）

```bash
# 压缩为gz格式，减小体积
gzip google_task_1.0.1.tar
# Compress-Archive -Path google_task_1.0.1.tar -DestinationPath google_task_1.0.1.zip

# 会生成 google_task_1.0.1.tar.gz
```

## 4. 在生产Linux服务器上导入

```bash
# 如果压缩了，先解压
gunzip google_task_1.0.1.tar.gz

# 导入镜像
docker load -i google_task_1.0.1.tar

# 或者使用
docker load < google_task_1.0.1.tar
```

## 5. 验证导入成功

```bash
# 查看本地镜像列表
docker images | grep google_task

# 运行容器测试
docker compose up -d
```


## 注意事项

1. **镜像大小检查**：导出前检查镜像大小
   ```bash
   docker images google_task:1.0.1
   ```

2. **传输方式**：可以使用scp、rsync或U盘等方式传输tar包
   ```bash
   scp google_task_1.0.1.tar.gz user@production-server:/path/
   ```

3. **空间检查**：确保生产服务器有足够磁盘空间
   ```bash
   df -h
   ```

4. **Docker版本兼容**：确保生产环境Docker版本与开发环境兼容

这样你就有了一个完整的离线部署方案！

## 5. nginx 入口镜像（部署模式 A，2026-09-29 新增）

前端入口由 nginx 承担：`/static/**` 与页面 HTML 由 nginx 直发（gzip + 7 天强缓存），
`/api/**` 反代 Flask。配置见 `dockers/nginx.conf`，设计依据
`docs/design/frontend-refactor/05-deployment.md` §3。

```bash
# 构建（上下文必须是仓库根目录；版本号与 google_task 保持一致）
docker build -f dockers/Dockerfile.nginx -t google_nginx:1.0.7 .
docker save -o google_nginx_1.0.7.tar google_nginx:1.0.7

# 服务器上
docker load -i google_nginx_1.0.7.tar
cd /opt/google_task && docker compose up -d
```

约定与注意：

- **每次发布**若改动了 `templates/` 或 `static/`，必须同步重建 nginx 镜像并升级版本号；
  `dockers/docker-compose.yml` 里 `google_nginx` 与 `google_task` 的 tag 一起改；
- 端口变化：对外 8081 归 nginx；Flask 只保留 `127.0.0.1:8082` 回环调试口（绕过 nginx 排障用）；
- 验证命令：

  ```bash
  # gzip 与强缓存头
  curl -H "Accept-Encoding: gzip" -I http://127.0.0.1:8081/static/css/bootstrap.min.css
  # 应看到 Content-Encoding: gzip 与 Cache-Control: max-age=604800
  # 页面与 API
  curl -I http://127.0.0.1:8081/backtest-multi-product/list   # 200
  curl http://127.0.0.1:8081/api/meta/enums                   # JSON 信封
  ```
