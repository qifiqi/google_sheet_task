我来帮你完成这个任务。首先构建镜像，然后导出为离线tar包，最后在生产环境导入运行。

## 1. 构建Docker镜像

```bash
docker build -t google_task:1.0.1 .
```

## 2. 导出为离线tar包

```bash
# 导出镜像为tar文件
docker save -o google_task_1.0.1.tar google_task:1.0.1

# 或者使用更明确的路径
docker save google_task:1.0.1 > google_task_1.0.1.tar
```

## 3. 压缩tar包（可选，方便传输）

```bash
# 压缩为gz格式，减小体积
gzip google_task_1.0.1.tar
# Compress-Archive -Path google_task_1.0.1.tar -DestinationPath google_task_1.0.1.zip

# 会生成 google_task_1.0.1.tar.gz
```

## 4. 在生产Linux服务器上导入

```bash
# 如果压缩了，先解压
gunzip google_task_1.0.1.tar.gz

# 导入镜像
docker load -i google_task_1.0.1.tar

# 或者使用
docker load < google_task_1.0.1.tar
```

## 5. 验证导入成功

```bash
# 查看本地镜像列表
docker images | grep google_task

# 运行容器测试
docker compose up -d
```


## 注意事项

1. **镜像大小检查**：导出前检查镜像大小
   ```bash
   docker images google_task:1.0.1
   ```

2. **传输方式**：可以使用scp、rsync或U盘等方式传输tar包
   ```bash
   scp google_task_1.0.1.tar.gz user@production-server:/path/
   ```

3. **空间检查**：确保生产服务器有足够磁盘空间
   ```bash
   df -h
   ```

4. **Docker版本兼容**：确保生产环境Docker版本与开发环境兼容

这样你就有了一个完整的离线部署方案！
