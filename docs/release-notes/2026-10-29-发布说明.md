## 主要变更（按 `docs/model_update/2026-10-月度汇总.md` 归纳）

### 安全与治理
- 配置写接口收权至管理员并对下发值脱敏；JWT 密钥改随机兜底堵 fail-open（ae92cab7）
- 定时任务 API 权限收紧；XSS/回填/导出等审查缺陷修复（fc44c28c）
- env 示例明确 JWT_SECRET_KEY 必填强随机；MySQL 密码出库为 .env 注入
- Mimosa 深度扫描 53 项复核闭环（11 HIGH 全误报，登记于 `docs/project-memory/已知问题.md`）

### 功能
- K线自有接口与页面重写、V3 回测分析页图表化、暗色主题接入
- 全局预览 Word 导出、v2 结果分析合并、URL 命名全库收敛入 `/api` 单命名空间
- 夏普比率支持自定义无风险利率；Word 导出弹窗改版；权重组合分析增强
- 多品回测：价格模式联动、全局参数表、产品 Google Sheet 卡片、股票代码筛选
- 随机价序列模式 `full_truncate`（全区间生成后按窗口截断）
- 任务管理/结果页体验优化；老模板移动端适配与 CSS 公共组件抽取
- C1.1 指数统一 AG 随机价口径，适配单品/多品回测；模型版本统一显示 C1.1.0

### 性能与稳定性
- 任务收尾 malloc_trim 归还 glibc arena 空闲页 + `MALLOC_ARENA_MAX=2`（线上 RSS 不回落修复，1.1.3 已部署）
- 仪表盘/列表 SQL 下推、日志批量刷、K线预计算并行、预览 LRU 等性能批次
- N+1 模式保留全区间组合并修复近年区间截断丢失
- 美股名称解析修复（Yahoo longName 兜底 + 进程内缓存）；Yahoo K线日期区间修复

### 规范
- 导出文件名统一规范扩展价格/复权段（`open/close/vwap/ohlc/rnd-hl/rnd-oc` + `qfq/hfq/raw`）；回测结果 CSV 与 Word/PDF 报告收编进统一命名（a7e40006）
