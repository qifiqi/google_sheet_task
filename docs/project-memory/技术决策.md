## 架构与分层

- **2026-09-04 数据层重构**：routes→services→repositories→models 单向分层；repository 返回原生 dict/list，HTTP 信封不下沉仓储层；写方法默认方法内 commit（保持断点续跑粒度）；统一响应信封 `{"status","code","message","data"}` 全库唯一。出处：`archive/design/data-layer-refactor/README.md`
- **2026-09-05 索引治理**：索引变更只走 Alembic 迁移，禁启动期私建；API 归位 URL 逐字节不变。出处：`archive/design/api-model-query-audit/README.md` §5
- **2026-09 执行链搬迁原则**：执行链行为"只搬不改"，行为变更单独立项。出处：`archive/design/code-audit-2026-09/03-task-code-refactor.md` §6.4
- **2026-09 全库无兼容层**：单一响应格式、单一异常体系、单一执行路径，无灰度/回退/双轨开关。出处：`archive/design/code-audit-2026-09/README.md` §3
- **2026-09 常量包纪律**：`app/constants/` 纯数据、零 IO、零 Flask 依赖，任何层可 import、禁反向依赖；STOCK_PARAM_METRIC_SPECS / summary_contract 刻意不收编。出处：`design/constants-audit-2026-09/01-常量审计报告.md` §1.3
- **2026-09 路由分层**：URL 与蓝图 endpoint 不变式；backtest_api 双蓝图共存、scheduler_service/worker 非同义列入"不改清单"。出处：`archive/design/routes-restructure-2026-09/README.md` §1/§3

## 前端

- **2026-09-07 前端静态化（D2/D8/D9）**：无构建普通 script（禁 module/defer）；templates 目录名保留；JS 三层收敛（api/business/components/utils）、api.js 唯一接口出口、分层形状对齐（彼时的）Vue 版。出处：`archive/design/frontend-refactor/README.md`
- **2026-09 移动端适配 P0**：admin 族侧边栏采用 offcanvas 方案 A；navbar.js"逐字节等价"红线在移动端行为升级时需登记修订。出处：`archive/design/mobile-adaptation-audit-2026-09/01-mobile-adaptation-audit.md` §3.3
- **2026-09-10 多指数 Word 报告（方案 C）**：引擎不动、报告层按基准列表循环组装，单指数 = 列表长度 1 天然单路径。出处：`archive/design/multi-index-word-report/README.md` §2
- **2026-09 绩效分析 V3**：红涨绿跌、系列色与涨跌色分离；`include_series` 缺省关闭；指标词表放前端（`static/js/common/metric-names.js`）不进 `app/constants`；V2 页零影响。出处：`archive/design/performance-analysis-v3/01-设计方案.md`
- **2026-10 Vue 3 SPA 移除**：`frontend/` 整体删除（源码存 `frontend.7z`），静态页面成为唯一前端；此决策终结 ponytail A1"双前端双轨并存"。出处：提交 62664028；AGENTS.md「双前端」

## 鉴权与子服务化

- **2026-09-05 鉴权边界**：鉴权/权限整体移交主服务，本项目不再新增权限类建设。出处：`archive/design/api-model-query-audit/README.md` §3.5
- **2026-09 SSO 入口换票**：`/login#sso_token` → `/api/auth/sso/exchange`，不做每请求透传；Token 走 fragment 不走 query；本地已有会话优先、不重复换票（"切换身份须先退出"为已接受后果）。出处：`archive/design/sso-integration-2026-09/README.md` §1/§2.1/§4
