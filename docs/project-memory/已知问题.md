## 当前暂缓（2026-10-21）

- **看门狗自动重启**：`app/services/task_watchdog.py` 代码保留但未启动；执行链仍写 `[NETWORK_RETRYABLE]`，当前无消费者，失败任务需人工重启。
- **pending 任务唤醒**：配额拒绝、C31 子任务启动失败等会停留在 `pending`，无后台唤醒器；需人工启动或重启进程。
- **多副本 / 独立 worker**：当前硬约束单 serving worker、单副本；启动期复位远端占用，Redis 锁失败直通。扩容前必须先拆分独立任务 worker。

## 架构后续（2026-10-21 复审，超出单批范围）

- **HTTP 无事务**：约 22 处 `transaction()/commit=False` 在 http 模式退化为顺序独立提交；跨仓储原子性需远端事务端点或补偿。已登记于 `docs/design/db-to-http-migration/README.md` §6.1。
- **任务无执行 deadline**：`TASK_TIMEOUT` 配置当前无消费方；看门狗停用，长任务可无限占用线程池，只能人工重启进程。
- **日志回灌慢写**：`TaskLogHttpRepository.create_logs` 逐行 2s 超时、失败丢弃，任务收尾延迟随日志量线性增长；待远端批量端点或异步回灌。
- **单副本/独立 worker**：启动期全局复位 + 进程内调度/线程池；多副本、滚动重启尚未支持。需独立任务 worker + leader/租约，见 AGENTS“当前暂缓”。
- **前端存量**：详情编辑弹窗仍保留隐藏 Token 字段；C 系创建页存在大量同构 JS；绩效分析 v1/v2/v3 并存。待前端专项清理。
- **仓库治理**：`.git` 约 9.5GB、`frontend.7z` 入库；需独立做历史/对象治理，不在功能批次处理。
- **鉴权边界**：`permission_required` 为空实现，接口授权上收主 Web；外部 Token 能力限制由主 Web 与 Google 侧承担。
