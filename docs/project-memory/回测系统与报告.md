# 回测系统与报告

## 单品回测（backtest_training_service.py）

`BacktestTrainingService(BaseGoogleSheetService)`，任务类型 `backtest_training`，必须绑定 `table_type=backtest_training` 的 Sheet：

1. `execute_task()`：app_context → 取消检查 → 合并默认配置 → `normalize_backtest_training_config` → `_init_google_sheet`（连接只建一次，逐组合复用并按需切换输入）。
2. `get_bdl(task, name, parameters, config_data)`：预计算参数组合 → 断点跳过 `_resolve_resume_start_index` → 逐步 `_execute_parameter_combination` → `_save_task_result` 持久化。
3. 完成：`_refresh_model_summary_index()` + 钉钉通知。

其它要点：支持 C7.0.3 单品回测（`_is_c7_0_3`、`_calculate_c7_0_3_index_returns`）；`_c3_to_c5_get_config` 做 C3→C5 配置适配；网络错误经 `_raise_retryable_network_error` 包装为可重启类型；同 Sheet 并发由 `BacktestSheetRunLock` 表 + `_start_next_pending_backtest_task` 排队接力（见 [任务系统与调度.md](任务系统与调度.md)）。

## 多品回测（backtest_multi_product_service.py）

`BacktestMultiProductService(BacktestTrainingService)`：

- 多个产品组合回测 + **固定产品缓存**（`BacktestProductResultCache` 表，batch_id + cache_key 唯一；`fixed_product_cache_exists` 命中时跳过该 Sheet 的锁抢占）。
- 组合收益按权重加权：`_build_portfolio_return_date`。
- 比例算法与排障见《多品数据回测比例算法审查》《多品数据回测维护说明》（已随历史 docs 删除，相关算法审查结论以代码注释为准）。

路由：`/backtest-training`（legacy `/backtest`）与 `/backtest-multi-product`（legacy `/backtest-multi`），页面均为 Jinja 模板（templates/backtest_training/、backtest_multi_product/），含 create / detail / list / result / global_preview。

## 全局预览

- 单品与多品都有 global_preview 构建（最近一次相关提交：回测全局预览构建与数据格式）。
- 路由 `app/routes/global_preview.py`：C7.0.3 全局预览页 + `/api/tasks/<id>/preview-group`。
- 多品支持比例计算接口 `calculate-ratios` / `ratios` PUT。
- 排障线索：全局预览指标空值通常源于收益序列缺失或模型分组缺失，优先核对 `TaskResultReturn` 与汇总索引。

### C1.1 Sheet 读取适配与双指数口径（2026-10-27）

`sheet_reader.py::get_google_sheet_data` 按标题分流，C1.1（sharable-manual 模板）为固定列读法（仿 C7/C5/C4 分支）：

- 输出区在 **H~M 列**（与 C5 系 A~N 布局不同）：H=YYMMDD 日期、I=Strike（=AG ext）、J=Day%（标的价格日涨跌）、**K=P/L%（策略累计收益，= 表内汇总 Total Return）**、**L=P/L%-Cum%（几何超额累计 = (1+K)/(1+指数累计)−1，不是策略收益）**、M=DD%；E/F 为 Result 汇总块（读 `E2:F26`，过滤空键与 `year#`）。start_return 取 **K 列**（与执行侧 `c1_1_output_column_k` 契约同列）；V1 指标管线按**累计收益**口径计算（`net = 1*(1+r)`）。曾经误取 L 列导致页面「模型收益」实为超额年度，2026-10-27 已改 K。
- 表尾公式残留行（`-`、`#VALUE!` 等）按解析失败 dropna 剔除；有效行不足 10 行报错。
- 非模板标题无兜底分支（返回 None，与 C3/C4/C5/C7 行为一致）。

**C1.1 存在两个指数口径**（后期可能两个都要，或加开关切换）：

| 口径 | 取数列 | 配置键 | 特点 |
|---|---|---|---|
| Strike/ext 指数（**当前实现**） | AG 列 ext（表内 Strike/I 列同值） | `c1_1_kline_ext_column`（缺省 AG） | 与表内 E/F 汇总自算完全一致（如实测表 Index Return 1136.75%、年化 33.05%） |
| 收盘价指数（未实现，备选） | AE 列 close | `c1_1_kline_close_column`（缺省 AE） | 标准 K 线收盘价口径；实测同一张表累计 1127.93%、年化 32.94%，与表内差约 0.1pp |

如需支持切换：在 C1.1 分支把指数列选择改为按 SystemConfig 开关（或在 `include_series`/payload 里加参数透传），两个口径各算一份 `index_return` 亦可（指标管线单次只消费一列，双份需跑两遍或扩展管线）。

## Word 回测报告

调用链：`POST /api/exports/backtest-reports/word` →

1. `app/dto/strategy_backtest_report.py::StrategyBacktestReportRequestDTO.from_payload`：HTTP JSON 校验。`RPT-S` 单品 / `RPT-M` 多品；收益来源三选一——直接 `returns`、`task_id(+return_series_id)`、Google Sheet（spreadsheet_id / sheet_name / google_sheet_url）；多品 `products` 各选来源并按权重合成；`filename / title / metadata / runtime_params`。
2. `strategy_backtest_report_service.py::StrategyBacktestReportService.generate_word()`：`_resolve_returns` 解析收益 → 多品 `_normalized_weights` 合成组合收益（`_cumulative_to_daily` / `_daily_to_cumulative`）→ XPLAnalyzer 算指标 → `_build_report_data` / `_sections`（净值、月度/日度汇总、盈亏、分布、超额、滚动、市场阶段、极端日、资金曲线等几十张表）→ `_build_chart_data`。
3. `strategy_backtest_report_charts.py::generate_report_charts`：Matplotlib（Agg 后端）绘图（折线、分组柱状、直方图、双直方图、回撤曲线）→ PNG；中文字体从根目录 `static/fonts/` 加载。
4. `word_export_template.py::generate_word_document`：校验并渲染通用 `title + footer + blocks` JSON（元数据、标题、正文、列表、表格、图片）→ python-docx 文档。渲染器不包含回测业务字段或专用 JSON 模板；统一使用微软雅黑，表格内容水平、垂直居中。

模板结构见 [策略回测报告模板使用说明.md](../guides/策略回测报告模板使用说明.md)。

## 导出体系（export_service.py / export_file_service.py / export_api.py）

`ExportService` 能力：`export_task_results`（按任务/按股票/批量 ZIP 流式）、`export_global_preview(/by_stock/batch)`、`export_backtest_result`、`export_xpl`、`export_model_summary`、`export_backtest_word`。返回 `GeneratedFile` / `GeneratedStream`。

`export_file_service.py` 是 Excel 构建核心，策略模式按任务类型分发 exporter：

- `C3TaskResultExporter` / `C5TaskResultExporter`（按模型分组 + 指标差异列 `c5_percent_difference`）/ `C7TaskResultExporter`（按股票代码归一、分 Sheet 归档 `build_c7_stock_code_export_archive`）/ `GenericTaskResultExporter`。
- 样式：`style_table_sheet`、列宽、数字/百分比格式；批量导出 `build_batch_export_file`。

HTTP 端点（`/api/exports`，见 [接口总览.md](接口总览.md)）：仅允许 `completed` 任务导出（`_completed_task_error`）；`ratios` 查询参数由 `_parse_ratios_query` 解析。

## 通用数值解析（app/utils/value_parser.py）

`parse_int` / `parse_float`（去千分位、拒绝 NaN/Inf）/ `parse_percent_like`（`5%` → 0.05）/ `parse_ratio` / `parse_date`。空值/布尔/非法值统一返回 default。导出与汇总索引等处统一使用它，避免散落的解析逻辑。
