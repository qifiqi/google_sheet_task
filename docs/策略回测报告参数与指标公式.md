## 1. 生成链路总览

入口：`POST /api/exports/backtest-reports/word`（`app/routes/export_api.py`）。

```
StrategyBacktestReportSchema（Pydantic 校验请求）
  → StrategyBacktestReportService.generate_word()
      ├─ _resolve_returns()      三类来源统一为「累计收益序列」
      │     RPT-S：returns / task_id / Google Sheet 三选一
      │     RPT-M：products 各自取收益 → combine_product_returns() 按权重组合
      ├─ performance_analyzer.get_calculate_metrics_v1_with_dataframes()
      │     → metrics.py 一次性算出全部指标 + index_df / start_df / excess_df
      ├─ _build_report_data()    指标 → 通用 Word JSON（metadata/heading/table 区块）
      ├─ _build_chart_data()     DataFrame → 图表数据（净值/回撤/超额/分布）
      ├─ generate_report_charts()  Matplotlib 生成 6 张 PNG（临时目录）
      ├─ generate_word_document()  python-docx 渲染 DOCX（图片嵌入文件）
      └─ 返回 (文件名, BytesIO)
```

输入序列的统一格式：按日期升序的 `{"date", "index_return", "start_return"}` 列表，其中 `index_return` / `start_return` 是**累计收益率**（小数，如 0.25 表示累计 25%），校验要求至少 2 个交易日、不能 ≤ -100%、日期不重复。

## 2. Word 生成参数

### 2.1 请求参数（`StrategyBacktestReportSchema`）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `report_type` | str | `RPT-S` | `RPT-S` 单品报告 / `RPT-M` 多品组合报告；`RPT-M` 但有效产品只剩 1 个时按 `RPT-S` 命名 |
| `title` | str | `量化策略回测绩效分析报告` | 报告主标题，同时用作页脚文字 |
| `filename` | str | 服务端生成 | 下载文件名，缺省规则见 2.4 |
| `returns` | list | `[]` | 直接传入的累计收益序列（单品三选一之一） |
| `task_id` | str | None | 从任务结果取收益序列（单品三选一之二） |
| `return_series_id` | int | None | 任务有多条收益序列时指定哪一条；必须属于该任务 |
| `google_sheet_url` / `spreadsheet_id` / `google_sheet_name` | str | None | V2 Google Sheet 来源（单品三选一之三）；`spreadsheet_id` 可从 URL 正则 `/spreadsheets/d/([a-zA-Z0-9_-]+)` 解析 |
| `products` | list | `[]` | `RPT-M` 专用，每个元素含自身收益来源 + `ratio`/`weight` + `stock_code` + `product_name` |
| `index_stock_code` | str | None | `RPT-M` 指定某个产品作为指数列（权重分配表会标注“(指数)”） |
| `weighting_mode` | str | `daily_compound` | 组合算法；旧版 `legacy_cumulative` 已停用，现在只有“日收益加权后复利”一种 |
| `weight_allocation` | dict | None | 权重分配表自定义覆盖；缺省由 `products` 自动生成（列为 股票代码/股票名/权重） |
| `metadata` | dict | `{}` | 报告头展示信息（模型版本/价格类型/无风险利率等，见 2.3） |
| `runtime_params` | dict | `{}` | 指标计算运行参数（阈值，见 2.2） |
| `group_key` / `ratios` | — | None | 前端全局预览页专用，仅 `export_service` 消费，`generate_word` 不使用 |

比例解析规则（`normalize_weight`）：`30`、`"30%"`、`0.3` 三种写法都归一为 `0.3`；**比例为 0 的产品不参与命名、组合与权重表**（全部为 0 时退回原列表，避免报告空白）。

### 2.2 计算运行参数 `runtime_params`（`MetricsRuntimeParamsDTO`）

| 参数 | 默认 | 用在报告哪里 |
|---|---|---|
| `market_downturn_threshold` | `-0.02`（-2%） | 7.1 市场下跌阶段：指数月收益低于该阈值的月份 |
| `market_upturn_threshold` | `+0.02`（+2%） | 7.2 市场上涨阶段：指数月收益高于该阈值的月份 |
| `daily_extreme_threshold` | `0.02`（±2%） | 7.3 极端单日：涨幅/跌幅超过阈值的天数与涨跌比 |
| `daily_drawdown_threshold` | `0.05`（5%） | 2.1 回撤发生次数：单日跌幅超过阈值的天数 |

支持字符串数字（如 `"-0.03"`），非有限数直接报错。计算结果会把**实际生效的阈值**回写到 metrics（`market_downturn_threshold` 等键），报告标题里的阈值文字即来源于此。

## 3. 数据预处理公式（指标与图表的共同输入）

### 3.1 多品组合（仅 RPT-M）

**(1) 权重归一化**

```text
w = 数字 / 100        当输入带 % 或数字 > 1 时
w = 数字              当输入是 0~1 小数时
```

```python
# portfolio_combiner.normalize_weight
if explicit_percent or number > 1:
    number /= RATIO_BASE        # RATIO_BASE = 100
```

白话：`30`、`"30%"`、`0.3` 三种写法都当成 30% 的权重。

**(2) 累计收益 → 日收益**（组合前必须做，因为要按日加权）

```text
净值(t)   = 1 + 累计收益(t)
日收益(t) = 净值(t) / 净值(t-1) - 1        （共同区间首日以净值 1.0 为基准）
```

```python
# portfolio_combiner.cumulative_to_daily
index_nav = Decimal("1") + Decimal(str(current["index_return"]))
result.append({"date": date,
               "index_return": float(index_nav / previous_index_nav - 1), ...})
```

白话：输入的“累计涨了多少”先还原成“今天比昨天涨了多少”。先截取共同日期再还原，避免首日错误引用区间外数据。

**(3) 日收益加权**

```text
R_组合(t) = Σ w_i × r_i(t)      对每个产品 i 的同一天日收益加权求和
```

```python
# portfolio_combiner.combine_product_returns
index_total = sum(Decimal(str(row_map[date]["index_return"])) * weight
                  for row_map, weight in zip(daily_maps, normalized_weights))
```

白话：组合一天的收益 = 各产品当天收益按比例加权。只用所有产品都有的**共同日期**（交集策略）。

**(4) 日收益 → 累计收益（复利还原）**

```text
净值(t)   = Π (1 + r(i))        从 1.0 开始逐日连乘
累计收益(t) = 净值(t) - 1
```

```python
# portfolio_combiner.daily_to_cumulative
index_nav *= Decimal("1") + Decimal(str(current["index_return"]))
result.append({"date": date, "index_return": float(index_nav - 1), ...})
```

白话：加权后的日收益再按复利连乘回去，得到组合的累计收益序列，后续所有指标和图表都消费它。

### 3.2 单序列派生（`metrics.py::_calculate_metrics_v1` 开头，指数/策略/超额三条序列都做）

**(1) 净值序列**

```text
净值(t) = 1 × (1 + 累计收益(t))
```

```python
base_df['index_net'] = 1 * (1 + base_df['index_return'])
base_df['start_net'] = 1 * (1 + base_df['start_return'])
```

白话：起始资金 1 元，累计收益 25% 时净值为 1.25。首日净值 = 1 + 首日累计收益（首日累计收益默认含起点前涨幅，见 §6）。

**(2) 两种超额收益**

```text
绝对超额：excess_return  = start_return - index_return          （逐日累计差，差值口径）
绝对超额净值：excess_nav = 1 × (1 + excess_return)
相对超额：excess_return_2 = start_net / index_net - 1           （几何超额，比值口径）
```

```python
base_df['excess_return']  = round(base_df['start_return'] - base_df['index_return'], 6)
base_df['excess_return_2'] = base_df['start_net'] / base_df['index_net'] - 1
```

白话：绝对超额是“两条净值曲线的涨幅差多少个百分点”；相对超额是“策略净值是指数净值的多少倍减 1”，即把指数当成 1 元基准时策略的走势。**超额收益曲线图画的是相对超额**（`excess_return_2`），报告 6.1 的“累计超额”用的是绝对超额最后一期。

**(3) 日收益率**

```text
日收益(t) = 净值(t) / 净值(t-1) - 1        （首日无前值，为 NaN，不参与统计）
```

```python
index_df['daily_return'] = (index_df['net_value'] / index_df['net_value'].shift(1)) - 1
start_df['daily_return'] = (start_df['net_value'] / start_df['net_value'].shift(1)) - 1
excess_df['daily_return'] = start_df['daily_return'] - index_df['daily_return']
```

白话：净值逐日环比。日超额收益 = 策略当天收益 − 指数当天收益（差值口径，非复利）。

## 4. 报告指标公式（按报告章节）

以下 `净值` 均指 3.2(1) 的序列；`月收益`、`日收益` 指 3.2(3) 与月度化后的序列。所有指标对**指数序列和策略序列各算一份**，超额列单独算。

### 一、收益类指标

**1.1 累计回报率**

```text
累计回报率 = 累计收益序列的最后一个值
```

```python
index_cumulative_return  = index_df['index_return'].iloc[-1]
start_cumulative_return  = start_df['start_return'].iloc[-1]
excess_cumulative_return = excess_df['excess_return'].iloc[-1]
```

白话：到期末为止一共涨了多少。超额列 = 策略累计 − 指数累计（服务端直接取 V1 算好的 `excess_cumulative_return`）。

**1.2 年化收益率**

```text
                    ⎛ 期末净值 ⎞ ^(365 / 持有天数)
年化收益率 = ⎝ 期初净值 ⎠                − 1
持有天数 = 期末日期 − 期初日期（自然日）
```

```python
# metrics.annualized_rate_return
total_return = end_value / start_value
annualized_return = total_return ** (365 / holding_days) - 1
```

白话：把任意时长的收益折算成“一年的速度”。例如两年涨 21%，(1.21)^(365/730) − 1 ≈ 10%，即平均一年 10%。分年度各算一份，另有 `all`（整个区间）一份。持有天数按**自然日**而非交易日。

**1.3 分年度收益率**

```text
年度收益率 = 本年最后一个交易日净值 / 对比基准日净值 − 1
对比基准日 = 上年最后一个交易日（第一年为当年首个交易日）
```

```python
# metrics.calculate_year_returns
comparison_day = previous_year_data.iloc[-1] if previous_year_data is not None \
                 else month_df.iloc[0]
annual_return = current_month_last_day['net_value'] / comparison_day['net_value'] - 1
```

白话：每个自然年从年初涨到年末的比例。报告表格里“超额(策略-指数)”列是两个年度收益率的展示减法。

**1.4 滚动收益（3/6/12 个月窗口）**

```text
滚动收益(t) = 最近 N 个月月收益率的算术平均
前置条件：总月数 ≥ 60（不足 5 年输出 reason，报告显示“数据不足5年”）
```

```python
# metrics.calculate_rolling_return
df[f'roll_{months}m'] = df[col].rolling(window=months).mean()
# 聚合导出（rolling_pair_summary）
index_avg = index_values.mean()
start_avg = start_values.mean()
win_rate  = (start_values > index_values).mean()      # 逐位配对
```

白话：任意时点往前看 N 个月，平均每个月赚多少。“策略胜率”是逐窗口配对比较：策略滚动收益高于指数滚动收益的窗口占比。

### 二、风险类指标

**2.1 最大回撤（MDD）**

```text
运行峰值(t) = max(净值[0..t])                     （历史最高净值）
回撤(t)   = (峰值(t) − 净值(t)) / 峰值(t)          （≥ 0）
MDD = max(回撤(t))
```

```python
# metrics.calculate_max_drawdown_by_year_and_total
running_max = yearly_data['net_value'].cummax()
yearly_data['drawdown'] = ((running_max - yearly_data['net_value']) / running_max) \
                              .where(running_max > 0, 0)
max_drawdown_row = yearly_data.loc[yearly_data['drawdown'].idxmax()]
```

```python
# 报告展示层取负（strategy_backtest_report_service._risk_section）
["最大回撤(MDD)", self._pct(-self._num(index_drawdown)), self._pct(-self._num(strategy_drawdown))]
```

白话：从历史最高点跌下来最深跌了百分之几。计算值为正数，报告里展示为负数（如 -15.32%）。按年各算一份（年度内独立 cummax），另有全区间的 `total`。

**2.2 最大回撤修复天数**

```text
逐日遍历净值：
  净值(t) ≥ 峰值 → 修复完成，累计本轮修复天数，更新峰值，计数清零
  净值(t) < 峰值 → 修复天数 + 1
最大回撤修复天数 = max(所有已完成修复周期)
```

```python
# metrics.maximum_number_of_backtest_repair_days
for i in range(1, len(net_values)):
    if net_values[i] >= peak:
        max_repair_days = max(max_repair_days, repair_days)
        peak = net_values[i]
        repair_days = 0
    else:
        repair_days += 1
```

白话：“从山顶跌到谷底再爬回山顶，最久的一次花了多少天”。只统计**已完成**的修复，区间结束仍未回本的不计。年度版本 peak 跨年累积（不因换年重置，键 `year_*_yearly_max_repair_days`）。注意报告 2.1 行标签写“年度最大”，但实际取值是整体区间版本 `*_maximum_number_of_backtest_repair_days`（年度字典已导出、该行未消费）。

**2.3 回撤发生次数（单日 > 阈值）**

```text
回撤发生次数 = count(日收益(t) < −阈值)      阈值默认 5%
```

```python
index_dd_count = (index_df['daily_return'] < -runtime_params.daily_drawdown_threshold).sum()
```

白话：单日跌幅超过 5% 的大跌天数（顺带算的 `index_dd_freq` 是频率，报告当前只展示次数）。

### 三、风险调整收益指标

**3.1 年化波动率**

```text
年化波动率 = 月收益率标准差(样本, ddof=1) × √12
```

```python

annual_std  = monthly_std * math.sqrt(annualization_factor)   # 12
```

白话：月度收益的离散程度放大到年度尺度。月度数据年化要乘 √12（方差×12，标准差开根号）。

**3.2 夏普比率**

```text
                月均收益 × 12        月均收益 × √12
夏普比率 = ───────────────────── = ─────────────
           月收益标准差 × √12          月收益标准差
```

```python
if annual_std != 0:
    sharpe_ratio = avg_monthly_return * annualization_factor / annual_std
else:
    sharpe_ratio = 0
```

白话：每承担 1 份波动换来多少收益。这里**无风险利率按 0** 处理；标准差为 0 时记 0。要求至少 2 个月数据；分年度要求至少 3 个月。

**3.3 卡玛比率**

```text
卡玛比率 = 年化收益率 / 最大回撤
```

```python
# metrics.calculate_kama_ratio
kama_ratio = item['annualized_return'] / drawdown
```

白话：每 1% 历史最深跌幅换来多少年化收益。`all` 年份的分母取**各年度最大回撤的最大值**（代码里显式覆盖，而不是 total 区间回撤）。

**3.4 索提诺比率**

```text
                     月均收益 × 12
索提诺 = ─────────────────────────────────
         √( Σ(负收益_i²) / N ) × √12
其中 负收益_i = min(月收益_i, 0)（正收益置 0），N = 全部月数（含正收益月份）
```

```python

sum_sq = (negative_returns ** 2).sum()
count  = len(negative_returns)                     # 全部期数

sortino_ratio = annualized_return / downside_std if downside_std != 0 else 0
```

白话：只惩罚下跌的夏普。波动只统计亏损月份的平方和，但**分母是全部期数**——上涨月份记 0 也占分母，所以亏损越零星，下行标准差越小。期数 ≤ 1 时记 0。报告展示的是月度版本（周度版本也算了，键 `*_weekly_sortino_ratio`）。

**3.5 超额夏普 / 超额索提诺**

```text
月超额 = 策略月收益 − 指数月收益
超额夏普   = 月超额均值 × 12 / (月超额标准差 × √12)
超额索提诺 = 月超额均值 × 12 / (负月超额标准差 × √12)     （正超额置 0 后再求标准差）
```

```python

        monthly_excess_return_standard_deviation * np.sqrt(12))
monthly_excess_returns_diff = monthly_excess_returns['monthly_excess_return_diff'].mask(
    monthly_excess_returns['monthly_excess_return_diff'] > 0, 0)

        monthly_excess_returns_diff.std() * np.sqrt(12))
```

白话：把夏普/索提诺的算法原封不动搬到“超额收益”序列上，衡量超额的稳定性。月超额全 ≥ 0（或常数）导致 std = 0 时结果为无穷大，统一出口转 None，报告显示 "-"。

### 5.5 日收益分布（左右双直方图）

这张图有四步计算：

**(1) 对称半轴（核心区间）** —— 用 0.5%/99.5% 分位数而不是极值：

```text
low  = 有序样本第 int((n−1)×0.005) 个
high = 有序样本第 min(n−1, ceil((n−1)×0.995)) 个
半轴 L = max(|low|, |high|, 0.01) × 1.05
```

```python
low = ordered[int((count - 1) * 0.005)]
high = ordered[min(count - 1, ceil((count - 1) * 0.995))]
return max(abs(low), abs(high), 0.01) * 1.05
```

白话：如果按最大/最小值定坐标轴，一两个极端日会把主体分布压扁。所以取中间 99% 样本的边界再放大 5%，保底 ±1%。超出的极端样本**折叠进两端边缘箱**（overflow bins），尾部频数不丢失。

**(2) 自适应分箱数** —— Freedman–Diaconis 估计 + 兜底，再取整到规整网格：

```text
span  = 2L
IQR   = 75 分位 − 25 分位
width = max( 2·IQR / n^(1/3) ,  span/60 )          ← FD 公式 / 兜底防重尾箱数爆炸
mag   = 10^floor(log10(width))
nice  = {1, 2, 2.5, 5, 10} × mag 中第一个 ≥ width 的值
箱数  = max(12, ceil(span / nice))
```

```python
iqr = ordered[int((count - 1) * 0.75)] - ordered[int((count - 1) * 0.25)]
width = max(2 * iqr / count ** (1 / 3), span / 60)
magnitude = 10.0 ** floor(log10(width))
for mantissa in (1, 2, 2.5, 5, 10):
    nice_width = mantissa * magnitude
    if nice_width >= width:
        break
return max(12, ceil(span / nice_width))
```

白话：FD 公式按样本量和四分位距自动估一个合适的箱宽（数据越散箱越宽，样本越多箱越细）；再向上对齐到 1-2-2.5-5 的“好看”刻度网格（比如 0.37% → 0.5%），箱数被自然限制在 12~60。

**(3) 边界与绘图** —— 两个子图共用同一组 `linspace(−L, +L, 箱数+1)` 边界和 sharey，样本先裁剪 `clip(v, −L, +L)` 再 `hist()`；0% 处画浅色竖参考线。

**(4) 对称百分数刻度** —— 步长从 1-2-2.5-5 网格自适应：

```text
mag  = 10^floor(log10( L / max_intervals ))       （默认 max_intervals = 4）
step = {1, 2, 2.5, 5, 10} × mag 中第一个满足 floor(L/step) ≤ max_intervals 的值
刻度 = {−k·step, …, +k·step}，关于 0 完全对称
有折叠样本时在 ±L 追加 "<-X" / ">+X" 边缘刻度
```

```python
magnitude = 10.0 ** floor(log10(span / max_intervals))
for mantissa in (1, 2, 2.5, 5, 10):
    step = mantissa * magnitude
    if floor(span / step) <= max_intervals:
        return step
```

小数位取能精确表示步长的最少位数（如 2.5% 刻度保留 1 位小数），避免刻度全部取整成 0 或出现拖尾小数。

## 6. 口径注意点汇总

1. **首月/首周收益基准 = 1**：`calculate_monthly_return_data` / `calculate_weekly_return_data` 的第一个周期基准硬编码为 1（而非当期首日净值），首期收益包含数据起点前的涨跌。代码内有 TODO 与 skip 的单测登记此问题。
2. **夏普的无风险利率 = 0**：报告头“无风险利率”只是展示字段，不参与计算。
3. **净值首日 = 1 + 首日累计收益**：输入是累计收益序列，默认首期累计收益含起点前涨幅；多品组合则强制从共同区间净值 1.0 重新还原，两种来源首日口径不同。
4. **两种超额并存**：表格口径多为绝对差（策略 − 指数）；超额曲线图为几何超额（策略净值/指数净值 − 1）。对比 Excel 数据时注意看的是哪个键。
5. **std = 0 除零**：超额夏普/超额索提诺在全同号序列下会除零，统一出口 `non_finite_to_none=True` 转 None，报告显示 "-"。
6. **滚动收益需要 ≥ 60 个月**：不足 5 年时输出 `reason`，报告对应行显示“{label}（数据不足5年，当前仅X.X年）- - -”。
7. **报告展示符号**：最大回撤计算为正、展示为负；2.2 分年度回撤的“超额回撤”列是**指数 − 策略**（正数 = 策略更抗跌），与其他“策略 − 指数”的超额列方向相反。
8. **卡玛比率 all 的分母**：取各年度最大回撤的最大值（显式覆盖），不是 total 区间回撤。
9. **索提诺下行标准差分母是全部期数**：正收益置 0 后仍参与计数（`SUMSQ/COUNT × √12` 的 Excel 同款口径），不是只数亏损月。
10. **日度指标的 NaN**：`daily_return` 首日为 NaN，mean/std/skew/kurt 自动忽略，但 `total_trading_days` 用 `len()` 统计含 NaN 行，因此“盈利天数 + 亏损天数 + 平盘天数”可能比总交易日少 1。
11. **图表不重算指标**：回撤、超额、分布等序列全部由服务层预计算，图表层只做数值清洗（非法值补默认）和渲染；改公式去 `metrics.py` / `_build_chart_data`，不要在图表层加业务口径。
