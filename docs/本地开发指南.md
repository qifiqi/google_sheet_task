# 本地开发指南

## 环境要求

- Python 3.11（Docker 镜像基于 python:3.11.10-slim）
- Node.js 18+（仅前端开发需要；package.json 未声明 engines，属约定值）
- 依赖：`pip install -r requirements.txt`（注意：requirements 中**不含 pytest**，跑测试需自行 `pip install pytest`）

## 环境变量

### 加载顺序（app/__init__.py::load_app_environment）

1. `.env`（不覆盖已有环境变量）
2. `.env.{APP_ENV}`（development / production / testing，同样不覆盖）

仓库内只有 `.env` 和 `.env.example` 入库；`.env.development` / `.env.production` / `.env.testing` 由部署机维护、不入库（Dockerfile 会 COPY 它们，本机构建镜像前需准备，否则构建失败）。

### 关键环境变量（.env.example 口径）

| 变量 | 说明 | 默认/示例 |
|---|---|---|
| APP_ENV | development / production / testing | development |
| SECRET_KEY | Flask session 密钥 | 必填 |
| JWT_SECRET_KEY | JWT 签名密钥；生产环境用默认值会 fail fast | 必填 |
| AUTH_ENABLED | 关闭鉴权仅允许 development | true |
| DATABASE_URL | 数据库连接串 | 未设置时默认 SQLite `instance/app.db` |
| MAX_CONCURRENT_TASKS | 最大并发任务数 | 5 |
| TASK_TIMEOUT | 任务超时秒数 | 3600 |
| LOG_LEVEL | 日志级别 | INFO |
| BASE_URL / PUBLIC_BASE_URL | 服务地址（钉钉通知链接等） | http://localhost:5000 |
| DING_TALK_ACCESS_TOKEN / SECRET | 钉钉机器人 | 可空 |
| DING_STREAM_CLIENT_ID / SECRET | 钉钉 Stream 微服务凭据 | run_ding.py 用 |
| SQLALCHEMY_ECHO / SQLALCHEMY_ENGINE_LOG_ENABLED | SQL 日志开关 | false |
| PORT / FLASK_DEBUG | run.py 监听端口与调试开关 | 5000 / false |
| GOOGLE_SHEET_HTTP_TIMEOUT 等 | Google IO 超时 | 见 app/config.py init_config |

### 数据库

- 开发默认 **SQLite**：`sqlite:///{项目根}/instance/app.db`（app/config.py::DEFAULT_DATABASE_URL）。
- 生产 **PostgreSQL**：`DATABASE_URL=postgresql://user:pass@host:5432/dbname`；requirements 也含 PyMySQL 可切 MySQL。代码中的 ensure_* schema 修补兼容三种方言。
- 引擎参数：`pool_pre_ping=True, pool_recycle=3600`。

### Google Token

- 默认 `data/token.json`（SystemConfig `token_file`），OAuth 用户凭证，gspread 授权用。可在管理后台"Token 池"页面导入多个。

## 启动

### 后端

```bash
python run.py            # host 0.0.0.0，PORT 默认 5000
```

Windows 快捷方式 `run.bat`（自动探测 venv，强制 APP_ENV=production）；Linux `run.sh`。

CLI 子命令：

```bash
python run.py init-db          # db.create_all + normalize_boolean_columns + 全部 ensure_* schema 修补
python run.py init-config      # 写入默认 SystemConfig（幂等）
```

> 常规 `python run.py` 启动**不会建表**（`_initialize_database_schema` 保持注释），首次跑起来前先执行 `init-db` 或 `flask db upgrade`；但默认 SystemConfig、RBAC（含默认账号 admin/admin123）和导航菜单会随每次启动幂等播种（`_initialize_system_metadata`），无需手动 init-config。

### 钉钉 Stream 微服务（可选）

```bash
python run_ding.py       # 独立进程，dingtalk-stream SDK
```

### 前端

```bash
cd frontend
npm install
npm run dev              # http://localhost:3000
```

Vite dev server 已配置代理到 `http://127.0.0.1:5000` 的路径：`/api`、`/admin/api`、`/backtest-training/api`、`/xpl/analyze`、`/xpl/v1/analyze`（vite.config.js）。其余路径（如 `/api/exports/*` 的部分 POST）若代理未覆盖，需自行在 vite.config.js 补充。

生产构建：`npm run build` → `frontend/dist`，由 Nginx 托管（见 [部署运维.md](部署运维.md)）。

## 测试

```bash
pip install -r requirements-dev.txt           # pytest（运行依赖不变）
pytest                                        # 全量：tests/unit + tests/integration
pytest tests/unit/test_p0_p1_refactor.py      # 主力回归入口（纯本地 SQLite）
pytest tests/unit/test_xxx.py::test_name      # 定向
```

- **目录结构**（2026-08-29 重组）：`tests/unit/` 为服务/工具层单元测试；`tests/integration/`
  为走 Flask test_client 的接口与页面测试；`tests/archive/` 是历史备份（legacy_services、
  旧模板拷贝、demos 等），经 `pytest.ini` 的 `norecursedirs` 排除，不参与收集。
- `tests/conftest.py` 提供 `app_factory` fixture：APP_ENV=development + SQLite 临时库，每个用例独立建/删表。绝大多数测试不依赖外部服务。
- `pytest.ini` 的 `addopts` 带 `--basetemp=.pytest_tmp`：绕开本机系统 Temp 目录 ACL 损坏
  （否则 setup 阶段报 `PermissionError: [WinError 5] ... Temp\pytest-of-<user>`）。
- **skip 用例**：`test_xpl_service.py`、`test_backtest_training_export.py`、
  `test_backtest_training_export_preview.py`、`test_model_summary_service.py` 中有 10 个
  `@pytest.mark.skip`，对应未完成的项目代码修复（metrics 日度分布与月度基线、超额回撤
  符号约定、export-preview download 路由未注册、CSV Content-Type 重复 charset），
  修复生产代码后取消对应 skip。
- **K 线/搜索类测试约定**：fake 的东方财富搜索结果必须含 `code`/`market`/`status`/
  `shortName` 字段（`StockSearchService._normalize_result` 契约），否则解析阶段即判"未找到"。

## 数据库迁移

```bash
flask db migrate -m "message"
flask db upgrade
```

注意本项目不完全依赖标准迁移流：`app/startup.py` 的 `_initialize_database_schema()` 内含 13 个 `ensure_*` 幂等修补（仅 `init-db` CLI 触发），线上脏库问题先看 `app/startup.py`，再看 [数据库模型.md](数据库模型.md) 的历史修复记录。

## 编码注意（Windows / PowerShell）

仓库大量中文注释与模板，PowerShell 默认编码会乱码：

```powershell
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
Get-Content .\run.py -Encoding UTF8
```

Git Bash 下读写文件同样显式 UTF-8。
