# 回测列表/详情轮询统一为 1 分钟（2026-09-22）

## 背景

多产品、单产品（backtest_training）任务域的各页面自动刷新间隔不一致：静态版两个列表页 5 秒、Vue 版两个列表页 5 秒、Vue 版单品详情页 5 秒；而静态版两个详情页与 Vue 版多产品详情页本就是 `60 * 1000`。5 秒轮询在任务数多、筛选条件叠加时对 `/api/tasks` 与日志接口压力偏大，且状态变化本就不频繁。

## 改动

全部收敛为 1 分钟一次（静态版以 `60 * 1000` 字面量、Vue 版 `usePolling { interval: 60 * 1000 }` 表达）：

| 页面 | 文件 | 间隔 |
| --- | --- | --- |
| 多产品列表（静态） | `static/js/pages/backtest_multi_product_list.js` | 5s → 60s |
| 单品列表（静态） | `static/js/pages/backtest_training_list.js` | 5s → 60s |
| 单品列表（Vue） | `frontend/src/views/backtest/List.vue` | 5s → 60s |
| 多产品列表（Vue） | `frontend/src/views/backtest-multi/List.vue` | 5s → 60s |
| 单品详情（Vue） | `frontend/src/views/backtest/Detail.vue` | 5s → 60s（仅 running/pending 时拉取任务+日志的既有逻辑不变） |

不变：静态版两个详情页与 Vue 多产品详情页原 `AUTO_REFRESH_INTERVAL`/60s 保持；手动刷新、翻页、筛选触发的主动加载不受轮询间隔影响；轮询静默（不闪 loading）语义不变。

## 验证

- `node --check` 两个静态列表 JS 通过；
- `cd frontend && npm run build` 通过。
