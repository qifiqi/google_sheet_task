# 2026-09-30 A股 ETF 资产总数接入东方财富延迟行情

## 背景

全局预览 / RPT-S 报告的"资产总数"列此前只覆盖海外市场（Yahoo `totalAssets`，未披露回退 `marketCap` 总市值）；A股分支在 `AkshareApi.get_total_assets` 中恒返回 `None`，且 `is_etf` 恒为 `None`，A股标的列恒显示 "-"，报告侧"ETF 资产值 vs 个股总市值回退"的列头语义对 A股无法区分。

## 改动

1. **`app/utils/dfcf_api.py`**（`DFCJStockApi` 新增，`etf_total_assets` 的 cn 分发对象）：
   - `get_total_assets_with_source(stock_code)` → `(资产值, 是否ETF)`；`get_total_assets(stock_code)` → 资产值（None 表示取不到）。
   - 数据源：东方财富延迟行情 `https://push2delay.eastmoney.com/api/qt/stock/get`，字段 `f57/f58/f116`（`fltt=2` 下 f116 单位为元，无需换算）。主站 `push2` 对部分出口 IP 返回 502，故统一走同 API 族的 `push2delay`；市值/规模属日频量级数据，15 分钟延迟无影响。
   - 口径：场内基金（ETF/LOF）`f116` = 最新价×总份额，即基金规模量级，等价海外分支 `totalAssets`；个股 `f116` 即总市值，等价 `marketCap` 回退。与披露的资产净值存在折溢价差（对流动性好的 ETF 极小），未采用天天基金 F10 的净值口径以保持单接口、单执行路径。
   - `is_etf` 判定：代码前缀，沪 `5xxxxx` / 深 `15-16xxxx` 为场内基金，与 AKShare K线路径同规则。
   - 市场 secid：沪 `1.`（5/6/9 开头）、深 `0.`（其余）；入参兼容 `.SH/.SZ` 后缀（剥离后取前缀判定）。
   - 网络行为：复用 `__get` 的 tenacity 重试与会话重建，并复用 `dfcf_kline_proxy_enabled` 代理开关（push2 系与 push2his 同 WAF 风险，同一开关覆盖同一风险域）。停牌/未披露（f116 为 "-"）或请求失败一律返回 `(None, None)`，不向调用方抛异常。

2. **`app/utils/etf_total_assets.py`**：cn 分支改走 `DFCJStockApi().get_total_assets_with_source(code)`，同时补全此前恒 `None` 的 `is_etf` 返回位；模块文档同步。TTL 缓存（成功 6h / 失败 10min）不变，批量报告对同一标的只触网一次。

3. **`app/utils/akshare_api.py`**：移除恒 `None` 的 `get_total_assets` 占位桩（唯一调用方已切走；数据源最终定为东方财富而非 AKShare，桩的"实现见 AkshareApi"约定失效）。

## 影响面

- `strategy_backtest_report_service` 的 `_etf_total_assets_texts`：A股 ETF 行开始携带真实资产值与 `is_etf=True`，含 A股 ETF 时列头按"资产总数"表述、全为个股时按"净资产/总市值回退"表述的既有逻辑自动生效，无需改动。
- 报告导出频度低 + TTL 缓存，新增触网量为每标的一次 GET；失败静默降级 "-"，不影响报告生成。

## 测试

- `tests/unit/test_etf_total_assets.py`：
  - cn 分发改测东财分发（代码透传、`(值, is_etf)` 透传、TTL 缓存命中不重复分发）；
  - 新增 `DFCJStockApi` 解析/标记用例：沪/深 ETF 标记 ETF、个股标记非 ETF、后缀剥离、`f116="-"` 与非数字代码降级 `(None, None)`、请求异常降级。
- 真实网络抽样（2026-09-30 实测，经代理池链路）：510300.SH → (1071.6亿, True)（≈最新价 4.432 × 份额 241.8 亿份）；159915 → (653.8亿, True)；588000 → (911.0亿, True)；161725（深市 LOF）→ (18.3亿, True)；600519 → (1.573万亿, False)；300750 → (1.347万亿, False)。ETF/LOF/个股判定、沪深 secid 路由、后缀剥离全部符合预期。
- 本机出口 IP 被东财 WAF 临时封禁期间，直连失败静默降级 `(None, None)`（不抛异常），开启 `dfcf_kline_proxy_enabled` 后经代理池恢复正常取数——验证了失败降级与代理两条路径。
