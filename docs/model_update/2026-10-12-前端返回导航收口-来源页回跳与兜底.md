# 前端跳转/返回全面收口：返回落到来源页

日期：2026-10-12　分支：dev_vue

## 背景

全站"返回"按钮此前是硬编码固定目标，与用户实际进入路径脱节。典型问题：**多品数据回测详情页 → "权重组合分析" → 点"返回"**，落到了绩效分析旧首页（`/performance-analysis/`），而不是用户刚离开的多品详情页。本次全面审计双前端（静态页 + Vue SPA）全部跳转/返回链路后统一收口：**"返回"语义 = 回到来源页；无来源信息时落到预置的真实页面（兜底）**。

## 语义与实现

### 静态页（templates/ + static/js/common/business/）

新增跨页共享组件 `static/js/common/business/back-link.js`（`Biz.backLink`，无依赖自足）：

- 返回 `<a>` 标记 `data-back-origin`，引入该文件即自动应用（DOMContentLoaded）；
- 判定规则：`document.referrer` 与当前页**同源且非本页自跳转**（pathname 相同视为自跳转，如刷新、换 task_id 重进）→ 返回链接改写为 referrer；新标签页直开 / 无 referrer / 跨源 → 保持 HTML 里写的兜底 href。
- 选择改写 href 而非 `history.back()`：目标确定（永远等于来源页 URL，含 query）、新标签页直开时仍可点（落兜底页）、中键/长按行为与普通链接一致。

接入页面（3 个，此前返回全部硬编码 `/performance-analysis/`）：

| 页面 | 兜底目标 | 典型来源（返回落点） |
| --- | --- | --- |
| `/performance-analysis/weight-combination` | `/performance-analysis/` | 多品回测详情页（`backtest_multi_product/detail.js` 的"权重组合分析"按钮带 task_id 跳入） |
| `/performance-analysis/v2` | `/performance-analysis/` | 侧边栏"回测数据分析"（来源任意页） |
| `/performance-analysis/v3` | `/performance-analysis/` | 直链进入为主 |

### Vue SPA（frontend/src/）

新增 `frontend/src/utils/navigation.js` 的 `useBackNavigation(fallback)`：

- 判定规则：vue-router 4 在 `history.state.back` 写入站内来源路由 fullPath → `router.back()`（原样回到来源页并保留其组件状态）；`back` 为空（新标签页直开/落地首屏）→ `router.push(fallback)` 兜底；
- `fallback` 支持字符串或 `() => string`（兜底目标依赖运行时状态时传函数）。

接入页面（9 个）：

| 页面 | 兜底目标 |
| --- | --- |
| `performance_analysis/WeightCombination.vue` | `/performance_analysis` |
| `performance_analysis/V1.vue`、`V2.vue` | `/performance_analysis` |
| `task/CreateC3.vue` … `CreateC7.vue` | `/task/list?version=cX`（各自版本） |
| `task/CreateC31.vue` | `/task/list?version=c3`（C31 入口在 c3 列表，产物也是 C3 子任务） |
| `task/Detail.vue` | `/task/list?version=<任务版本>`（C3 及未知版本落缺省 c3，与列表页缺省一致） |

### 创建页提交成功跳转 push → replace（7 处）

创建页提交成功后的跳转由 `router.push` 改为 `router.replace`，使已提交的表单页不留在历史栈——详情/列表页的"返回"（`history.back` 语义）因此落回列表，而不是回到已提交的表单：

- `task/CreateC3/C4/C5/C7.vue`（→ `/task/<id>`）、`task/CreateC31.vue`（→ `/task/list?version=c3`）
- `backtest/Create.vue`（→ `/backtest/list`）、`backtest-multi/Create.vue`（→ `/backtest-multi/list`）

## 审计结论：核对过、无需修改的链路

- **backtest_training / backtest_multi_product 全系列静态页**（detail/result/global_preview/result_export_preview/create）：返回链接由页面 JS 按任务上下文填充（detail/list 地址 + 分页状态参数），落点正确；
- **google_sheet C3/C4/C5/C7/C31 create/detail**："返回首页"实际指向对应版本任务列表（`/google-sheet/?version=cX`），主要入口即列表页与创建完成跳转，落点为真实页面，保持不变（文案"返回首页"与落点略有出入，属历史文案，行为合理未动）；
- **`google_sheet/merge_export.html`**：返回列表 → `/google-sheet/?version=c3` ✓；
- **Vue backtest/backtest-multi 的返回列表/详情/结果/全局预览**：均带分页上下文 query（`backListQuery`/`pagingLink()`），正确；
- **`template-auth.js` 登录异常页"返回首页"** → `/admin/dashboard` ✓。
