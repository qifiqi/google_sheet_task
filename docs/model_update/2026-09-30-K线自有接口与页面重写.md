# 2026-09-30 K线自有接口与页面重写（多数据源 + klinecharts 图表）

## 背景

`/admin/eastmoney-kline`（iframe 嵌 `/eastmoney-kline`）原页面为 layui + jQuery + CDN 产物，
浏览器直连东方财富 JSONP 接口取数，与项目"接口唯一出口 api.js / 统一信封 / 鉴权收敛"的约定脱节。
本次将其收敛为：本服务自有 K 线接口 + Bootstrap 原生 JS 页面 + klinecharts 图表组件。

## 后端改动

### 1. 新增 `GET /api/klines`（`app/routes/stock_api.py`，与 `/api/search-stocks` 同蓝图）

- 请求（Pydantic `app/schemas/stock.py::StockKlineQuerySchema`，经 `parse_query`）：
  `stock_code`（必填）、`market_type`/`exchange_market`/`stock_name`（可空）、
  `data_source`（dfcf/qq/akshare/yahoo/tdx/database，默认 dfcf）、
  `kline_type`（1/5/15/30/60/101/102/103，默认 101）、`limit`（2–10000，默认 2000）、`adjust_type`（0/1/2 或别名）。
- 响应：统一信封，`data = {stock_code, stock_name, data_source（行内实际生效值）, kline_type, adjust_type, rows[]}`；
  行为白名单投影 `{stock_date, open, close, high, low, volume(股), amount, vwap, amplitude, pct_change, change, turnover_rate, data_source}`。
- 分钟周期仅允许 dfcf/qq（其余源日线口径），违规 400。
- `KlineService` 请求间惰性单例复用（内部持有上游会话）。

### 2. `KlineService` 支持分钟/周/月周期（`app/services/kline_service.py`）

- `get_kline_data(..., kline_type="101")` 新增关键字参数，经 `_fetch_external` → request dict 三层透传至
  `_fetch_dfcf`/`_fetch_qq`。
- **内部 K 线库读/写仅限日线**（`kline_type ∈ {"", "101"}`）：分钟/周/月周期绕开内部库直取外部源，
  防止非日线行污染日线库（读写两处都加了守卫）。
- `_normalize_stock_date` 新增纯数字 `YYYYMMDD`/`YYYYMMDDHHMM[SS]` 解析（腾讯系日期）。
- `_normalize_rows` 行新增 `stock_datetime`（来源日期带时间部分时为 `YYYY-MM-DD HH:MM`，日线为空串）：
  分钟K线同日多根，`stock_date` 仍归属到日（内部逻辑零变化），展示层用根级时间。
  `/api/klines` 输出行的 `stock_date` 取 `stock_datetime || stock_date`。
- **周K/月K聚合推算**：dfcf/qq 原生提供周月K（直传周期）；akshare/yahoo/tdx/内置库仅日线口径，
  请求 102/103 时自动放大日线拉取条数（周×7、月×31）并按 `_aggregate_klines` 本地聚合
  （周按自然周周一、月按 YYYY-MM 分组；首开/末收/最高/最低、量额求和、vwap=Σamount/Σvolume、
  行日期=组内最后交易日，聚合后截最新 limit 根）。振幅/涨跌幅等衍生指标不在聚合层伪造，
  由页面端按收盘序列推算。

### 3. 腾讯分钟K线补缺（`app/utils/qq_api.py`）

- 原 `KLINE_TYPE_MAP` 里的 `min5/min15/...` 为死配置：分钟周期走 `fqkline` 端点腾讯直接报错。
- 拆出 `MINUTE_TYPE_MAP = {1:m1, 5:m5, 15:m15, 30:m30, 60:m60}`，分钟走独立端点
  `MKLINE_URL（/appstock/app/kline/mkline）`，param 不带复权段；游标翻页复用既有循环
  （腾讯分钟游标为 `YYYYMMDDHHMM`，恰好被新的日期解析接住）。行解析复用 `_parse_kline_item`（A股手→股换算不变）。

## 前端改动

### 页面重写（去 layui/jQuery，项目风格）

- `templates/eastmoney_kline/index.html`：Bootstrap 5 骨架 + template-auth（独立页无侧栏，admin 壳 iframe 照旧嵌入）；
  表单字段：股票查询（候选下拉）、K线周期、**数据源（新增）**、条数、复权；表格卡头部带导出文件名/日期排序/
  **K线图按钮（新增）**/导出Excel；波动率分析区结构保留（原生 date 输入替代 laydate）。
- `static/js/pages/eastmoney_kline_index.js`：普通 script 顶层函数风格（对齐 global_preview_index.js），
  取数走 `Api.endpoints.stock.search / stock.klines`（禁手写 /api/* URL），表格 innerHTML + escapeHtml 渲染，
  波动率/年度成交额计算逻辑逐值保留；vwap≤0 视为缺失（腾讯分钟线无成交额）。
  **衍生指标推算**：内置K线库（cn/en 日线优先命中，行 data_source=database）/akshare 行不带
  振幅/涨跌幅/涨跌额（后端输出 null），前端对缺失项用昨收推算（振幅%=(高-低)/昨收、
  涨跌额=收-昨收、涨跌幅%=(收-昨收)/昨收，与东财口径一致）；换手率无推算来源，保持 "-"。
- `static/js/common/api.js`：stock 域新增 `klines(query)`。
- `static/css/pages/eastmoney_kline_index.css`：重写为 Bootstrap 之上的少量自定义（候选下拉/图表容器等）。
- 删除 layui 专属资源：`static/eastmoney-kline/js/http/eastMoneyKlineApi.js`（直连东财 JSONP）、
  `static/eastmoney-kline/js/utils.js`、`static/eastmoney-kline/css/extend.css`；
  保留 `static/eastmoney-kline/js/excelExport.js`（纯 SheetJS 封装，无框架依赖）。

### K线图查看（klinecharts 公开组件）

- 引入 `static/js/klinecharts-10.0.2.min.js`（UMD 本地 vendored，无 CDN）。
- 表格卡「K线图」按钮 → Bootstrap modal（modal-xl 定高容器）→ `klinecharts.init` 渲染：
  主图蜡烛（红涨 #ef4444 / 绿跌 #159a57）+ MA(5,10,20,60)，副图指标下拉单实例切换（VOL 默认 / MACD / KDJ / RSI / BOLL / 无）。
- **明暗主题适配**：图表配色经 `chartThemeStyles()` 跟随 html `data-bs-theme`（网格/坐标轴/十字线两套色），
  init 时取当前主题、重开/换股时 setStyles 同步；init() 里 MutationObserver 监听 `data-bs-theme`
  变化实时换肤。页面 CSS 补齐暗色下 `.kline-chart-dialog` 的 modal-content/header/btn-close 配色
  （项目 Bootstrap 无原生 data-bs-theme 支持，theme.css 未覆盖 modal）。
- v10 API 对接要点（踩坑记录）：数据供数走 `chart.setDataLoader({ getBars })`，
  **callback 签名为 `(bars, more)` 两参数**（非对象）；`getBars` 仅在 symbol/period/dataLoader 三者齐备时触发，
  故每次渲染按查询参数 `setSymbol`（携带 pricePrecision 3）+ `setPeriod`（klt→Period 映射）+ `setDataLoader`；
  v10 无 `setPriceVolumePrecision`（v9 API，勿复用）。

## 已知限制

- 分钟周期仅东方财富/腾讯源支持（接口 400 校验）；周/月K所有源可用——非原生源由日线聚合推算。
- 腾讯分钟端点（mkline）不提供成交额 → amount=0、vwap 按缺失展示。
- cn/en 市场日线会先读内部 K 线库，内部库不可达时该组合报 500（既有行为，未改动）。
