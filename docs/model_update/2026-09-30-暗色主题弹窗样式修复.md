# 2026-09-30 暗色主题弹窗（Modal）样式修复

## 问题

暗色主题（`html[data-bs-theme="dark"]`）下，所有静态页面的弹窗（Bootstrap Modal）仍为白色背景：

- 弹窗标题等文字继承了暗色主题的浅色文字色（`#e5e7eb`），落在白色弹窗背景上几乎不可见（如「路由表管理 → 新增路由」弹窗标题）；
- 弹窗内的 `form-control`/`form-select` 又被 theme.css 强制为暗色底，形成"白弹窗 + 暗输入框"的明暗割裂；
- 关闭按钮 `btn-close` 是深色图标，暗色背景下不可见；
- `form-check-input`（开关/复选）未选中态轨道为 `rgba(0,0,0,.25)`，暗色背景下几乎不可见。

## 根因

项目使用 **Bootstrap 5.2.3**（`static/css/bootstrap.min.css`），不支持 5.3 的原生 `data-bs-theme` 暗色模式。暗色主题完全依赖 `static/css/common/theme.css` 中 `html[data-bs-theme="dark"] …` 手动覆盖，而该文件此前覆盖了 card/table/form/dropdown/list-group 等，**遗漏了 modal 组件**；Bootstrap 5.2 编译产物中 `--bs-modal-bg` 硬编码为 `#fff`，于是弹窗恒为白色。

## 修复

仅改 `static/css/common/theme.css`，为暗色主题补充 modal 组件覆盖（所有静态页面弹窗统一生效，含页面级 JS 动态创建的弹窗）：

- `.modal-content`：背景 `#182132`、边框 `#2a3648`、文字 `#e5e7eb`（与 card 同一套配色）；
- `.modal-header` / `.modal-footer`：分隔线颜色 `#2a3648`；
- `.btn-close`：`filter: invert(1) grayscale(100%) brightness(200%)` 反白；
- `.form-check-input`：未选中态暗底 `#0f172a` + 边框 `#334155`；选中态 `#3b82f6`（与主题 focus 色一致）；focus 态同主题蓝色光圈。

## 验证

以与线上一致的 CSS 链路（bootstrap.min.css + template-auth.css + theme.css + sidebar.css）构造暗色「路由表管理 + 新增路由弹窗」静态复现页，无头 Chrome 截图经视觉验收：弹窗整体暗色、标题/label/placeholder/开关/按钮全部清晰可读，无明暗割裂与布局回归。

## 影响范围

- 纯 CSS（common/theme.css），无 Python/JS 改动，不影响接口与任务链路；
- 浅色主题不受影响（所有新增规则都限定在 `html[data-bs-theme="dark"]` 作用域内）；
- 各页面级 CSS 中已有的 `html[data-bs-theme="dark"]` 覆盖（如 batch-export-summary 等）优先级不变。
