## P0（必现功能错误）

1. **登录成功后白屏**（`frontend/src/views/Login.vue`）：缺省跳转 `/admin/dashboard`，但 SPA 路由表仪表盘为 `/admin`（`router/index.js`），无 `admin/dashboard` 路由也无 `:pathMatch(.*)*` 兜底，SSO 换票与无 `next` 账密登录均命中空路由。修复：`resolveNextUrl()` 缺省回退改为 `/admin`。注意：外部显式传 `?next=/admin/dashboard` 仍无对应路由，主服务 SSO 标准入口不带 next，不受影响。
2. **任务详情"手动刷新"按钮点击报错**（`frontend/src/views/task/Detail.vue`）：模板引用 `handleManualRefresh` 但 `<script setup>` 未定义（构建不校验 setup 绑定，属运行时错误）。修复：补定义——`manualRefreshing` loading + `loadTask()` + `loadLogs()/loadResults()` 全量刷新 + 成功/失败提示（对齐静态版 `google_sheet_detail.js` 的 manualRefresh 语义，终态任务也可刷新）。

## P1（特定条件下出 bug）

3. **C4/C5 指标详情弹窗数值被 C7 归一污染**（`frontend/src/views/task/components/ResultGroupsCards.vue`）：`buildMetricCell` 对所有版本无条件给 `formatMetricText` 传 key，导致 C4/C5 的 D10/D15/D18/D19 被 C7 的 `normalizeLegacyC7MetricValue` 误乘 100（3.2 → "320.00%"）。老版仅 C7 传 key（c7_detail.js:1258 vs c4:1171/c5:1122）。修复：`props.version === 'c7'` 才传 key，卡片表格六列 key（D2-D7/D8-D13）本就不命中归一集合，不受影响。
4. **配置编辑弹窗批量粘贴产品代码不拆分**（`frontend/src/components/ConfigEditDialog.vue`）：`el-select allow-create` 不按分隔符拆分，粘贴 `600000,600001` 生成单个合并标签并作为一条 `parameters[0]` 提交；placeholder 却承诺批量粘贴。修复：`@change` 时按老版 chips 的 `/[\s,，]+/` 规则拆分去重（程序赋值不触发 change，无递归）。
5. **失效会话 + sso_token 场景换票被打断**（`frontend/src/api/index.js`）：401 刷新失败分支无条件 `window.location.href = '/login?...'` 全页跳转，静态版有 `if (!isLoginPage())` 守卫（template-auth.js `redirectToLogin`）。SPA 版在登录页复用本地会话失败时被全页重载打断，内存中的 sso_token 丢失（hash 已被消费清除），且 next 被污染为 `/login` 自身。修复：守卫改为 `window.location.pathname.startsWith('/login')` 时不跳转，仅清令牌并 reject（Login.vue 的 `fetchUser` catch 返回 null 后继续走 `ssoExchange`，闭环成立）。
6. **admin 三页定时器卸载竞态**（`Logs.vue` / `Tasks.vue` / `Dashboard.vue`）：`onMounted` 里 `await getConfig()` 之后才创建轮询定时器，若期间切走页面，`onUnmounted` 先执行（定时器尚为 null 无可清），事后创建的轮询永不停止（Logs 为 5s 全量 + 3s 增量双轮询，失败每 5s 弹错）。修复：三处加 `disposed` 标志——卸载时置位，创建前检查；Logs 的 `startTimers` 入口检查，Tasks/Dashboard 的 `customPollTimer` 创建条件补 `!disposed`。
7. **静态版新移动端顶栏"切换主题"按钮点击无响应**（`static/js/template-auth.js`）：`bindThemeToggles` 逐节点绑定且在 `bootstrapProtectedPage` 首个 await 之前同步执行，早于 navbar.js 渲染（脚本顺序 template-auth → navbar，DOMContentLoaded 按注册顺序执行），侧栏/顶栏新注入的三处 `data-template-theme-trigger` 永远绑不上；移动端适配原始诉求（P0：手机端无法切主题/退出登录）中"切主题"一项实际落空。修复：改为 document 级事件委托（幂等一次绑定，覆盖任意时机注入的按钮），并在 `loadNav()` 后重跑一次 `applyTheme` 同步晚渲染按钮的图标/文案初始态。登录页路径同函数，行为不变。
