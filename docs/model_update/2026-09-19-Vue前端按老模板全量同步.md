# Vue 前端按老模板全量同步（2026-09-19）

对照纯静态版（`templates/` + `static/js/pages/`）对 `frontend/` Vue 3 SPA 做的一轮系统性差异同步。老模板是功能基准，迁移是翻译不是重设计；本轮同步后全站静态内联 `style="..."` 归零，新增 UI 全部使用 Element Plus 原生组件与属性。

范围：36 个既有文件修改 + 2 个新组件，`npm run build` 通过。上一轮记录见 `docs/design/vue-frontend-fix-2026-09/`（其遗留项中的"C 系详情版本分支"本轮已完成）。
