# Word 报告导出接入水印/页眉/页脚模板底板

日期：2026-10-15　分支：dev_vue

## 背景

策略回测 Word 报告此前由 `word_export_template` 从空白文档起步自行绘制全部样式，没有公司品牌要素。现提供模板底板 `app/assets/report_template.docx`（由业务方提供的《报告模板.docx》清空正文后得到），要求：内容仍由系统生成，水印、页眉（logo + 免责声明）、页脚（页码 + 报告名）随模板走；模板文件缺失时回退原有空白文档路径。

模板解剖（决定实现方式的关键事实）：

- **水印是图片水印**：三个页眉部件各含一个 VML shape（`WordPictureWatermark*`）引用 `word/media/image7.png`（整页平铺"迦柏资本 JASPIL CAPITAL"图案，负 z-index 垫于正文之下）。
- **实际生效的只有默认页眉页脚**：`settings.xml` 中 `evenAndOddHeaders=false`、`titlePg=false`，header1/3、footer1/3（偶数页/首页变体）存在但休眠。
- **页面几何与模板 Normal 样式同 `WORD_STYLE` 逐值一致**（Letter 8.5×11″、边距 1.25″/1.25″/1″/1″、微软雅黑 10.5pt、段后 6pt、1.25 倍行距），导出器所需的内置样式（heading 1-3、List Bullet、Table Grid、Title）全部齐全。
- python-docx 打开→保存的往返不破坏页眉/页脚/VML 水印（仓库里这份模板本身就是 python-docx 清空正文产出的，已实测验证）。

## 行为变化

- 有模板（正常部署）：每页带水印、页眉 logo+免责声明、页脚"页码 + 报告名"；导出件约 1.3MB（水印图 897KB 内嵌）。
- 模板缺失：回退空白文档，行为与改动前完全一致（页面自管 + 灰色居中页脚），日志 WARNING 提示回退路径。
- 两种模式下文档属性 author 均为"迦柏资本"，不再残留模板的 `python-docx`/`s32253`/打印时间。

## 注意事项与遗留

- 模板页脚的报告名是**可被替换的文本**（保留 run 样式原位替换），页码域（SDT 包裹的 PAGE 域）不受影响；若将来报告类型需不同页脚版式（如封面页不带页眉），翻转 `settings.xml` 的 `titlePg` 并维护 header3/footer3 即可。
- 正文标题颜色仍按 `WORD_STYLE` 覆盖为 1F4E79/2F5597（模板内置 heading 为 Word 默认蓝）；如需与模板原样式统一，改 `WORD_STYLE["headings"]` 即可。
- `app/assets/` 目前未纳入 git 跟踪，提交时需 `git add`，否则线上镜像无模板将静默回退空白样式。
- 全量回归 `tests/unit tests/integration`：878 passed / 1 failed——`test_template_crud_envelope` 为存量失败（stash 本改动后同样失败，C3TaskConfig 校验问题，与本次无关）。
