# 修改文档：索提诺比率接入无风险利率

- 日期：2026-09-17
- 分支：dev_vue
- 范围：绩效分析（performance_analysis）V1 指标引擎的索提诺比率公式
- 性质：公式扩展（rf 可选参数，默认 0），**不修改数据库 schema/迁移/数据，默认行为零变化**

## 背景

2026-09-16 夏普比率接入 rf 后，对全部指标公式做了一轮盘点：V1 引擎里「理论上应含 rf」的比率只有夏普（已接）与索提诺（未接）；超额类指标（超额夏普/超额索提诺/年超额/跑赢年份等）基于「策略 − 指数」差值序列，rf 双边抵消，接入无意义；绝对收益/回撤类指标无 rf 概念。本次把唯一有意义的扩展点——索提诺比率——按与夏普完全相同的口径接通 rf。

## 口径

```
索提诺 = (月均收益 − rf/周期数) × 周期数 / 下行标准差    即 (年化收益 − rf) / 下行波动率
周期数：月度 12、周度 52；rf=0 时与历史公式逐位一致（IEEE 754 下 x − 0 == x）
```

- 与夏普的区别：分母是下行标准差（负收益掩码后 √(SUMSQ/全部期数) × √周期数），rf 只进分子。
- 结果 dict 中的 `annualized_return` / `avg_return` / `downside_std` 等**描述字段保持原值**（不扣 rf），只有 `sortino_ratio` 受影响——这些字段在 Word/前端表格中按"年化收益"等原义展示，不能跟着变。
- 生效范围与夏普一致：`runtime_params.risk_free_rate` 进入的链路（三个 Word 导出弹窗：绩效分析 v2 / 回测训练结果页 / 多品全局预览）。页面 analyze、任务执行期落库指标、粘贴文本分析不传 rf，恒 0，历史数值不变。

## rf 在指标体系中的完整去向（盘点结论，含本次）

| 指标 | 公式 | rf |
|---|---|---|
| 夏普比率（指数/策略 × 全部/分年/滚动年） | (年化收益 − rf) / 年化波动率 | ✅ 9-16 接入 |
| 索提诺比率（指数/策略 × 月度/周度 × 分年/整体） | (年化收益 − rf) / 下行波动率 | ✅ 本次接入 |
| 超额夏普 / 超额索提诺 | 月超额均值×12 / (月超额std×√12) | ❌ 差值序列，rf 双边抵消，不加 |
| 年超额收益 / 跑赢年份 / 月超额系列 | 策略 − 指数 | ❌ 语义为相对基准，rf 不适用 |
| 年化收益/回撤/卡玛/胜率/修复天数/波动率/分布等 | — | ❌ 无 rf 概念 |

## 兼容性

- rf 缺省 0.0：`(avg − 0/N) × N` 在浮点上与 `avg × N` 逐位一致，存量报告、落库指标、测试全部不受影响。
- Word 导出缓存键含整个 payload（含 runtime_params），行为与 9-16 夏普改造相同，无需处理。
