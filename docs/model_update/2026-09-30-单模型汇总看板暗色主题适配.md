# 2026-09-30 单模型汇总看板暗色主题适配

## 问题

暗色主题下「单模型汇总数据看板」（`templates/admin/model_summary.html`）顶部 5 张 KPI 指标卡仍是浅色底，与暗色页面强烈割裂：

- `.summary-market-card` 硬编码 `background: #f8fafc`（浅灰），而卡内 `.summary-main-number` 等文字用 `var(--bs-body-color)`，暗色主题下是浅色（`#e5e7eb`）——浅底叠浅字，"196 / 股票总数"几乎不可读；
- 4 张 ReturnBeats 卡（`.threshold-positive/medium/strong/extreme`）硬编码马卡龙浅底（`#f0fdf4`/`#f7fee7`/`#fffbeb`/`#fef2f2`）+ 深色文字，暗色页面中刺眼；
- 表格 `.metric-positive`（`#198754`）/`.metric-negative`（`#dc3545`）为浅色主题设计的深色调，暗背景上对比度不足。

## 根因

与同日弹窗问题同源：项目用 Bootstrap 5.2.3，暗色主题完全靠 `html[data-bs-theme="dark"]` 手动覆盖；该页面样式是模板内联 `<style>`，KPI 卡配色只写了浅色一套，无暗色分支。

## 修复

仅改 `templates/admin/model_summary.html` 内联样式，新增 `html[data-bs-theme="dark"]` 作用域覆盖（沿用仓库暗色惯例：同色系半透明底 + 亮色文字，浅色主题不受影响）：

- 市场结构卡：底色 `#182132`、边框 `#2a3648`（与 theme.css 的暗色 card 一致），文字走 CSS 变量自动变浅；
- 四张 ReturnBeats 卡：底色改为对应色系 12% 半透明（`rgba(34,197,94,.12)` / `rgba(132,204,22,.12)` / `rgba(245,158,11,.12)` / `rgba(239,68,68,.12)`），边框同色系 24%-28% 透明度；文字改亮色（`#4ade80` / `#a3e635` / `#fcd34d` / `#fca5a5`）；进度条填充同步提亮（`#22c55e` / `#84cc16` / `#f59e0b` / `#ef4444`）；
- `.metric-positive`/`.metric-negative` 暗色下改 `#4ade80` / `#f87171`。

## 验证

以与线上一致的 CSS 链路（bootstrap.min.css + theme.css + 页面内联样式）构造暗色复现页并注入模拟数据（含 KPI 卡数值、参数标签、正负指标表格），无头 Chrome 截图经视觉验收：5 张卡均为暗色调且明度统一、文字/进度条清晰，正值绿色 `rgb(74,222,128)`、负值红色 `rgb(248,113,113)` 像素采样确认可区分，无布局回归。

## 影响范围

- 纯模板内联 CSS，无 Python/JS 改动，不影响 `/admin/api/*` 汇总接口；
- 所有新增规则限定在 `html[data-bs-theme="dark"]` 作用域，浅色主题渲染零变化。
