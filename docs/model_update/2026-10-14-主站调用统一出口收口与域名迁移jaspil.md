# 主站调用统一出口收口：参数回推与代理获取并入 app/remote_api，域名迁移 jaspil.cn

日期：2026-10-14　分支：dev_db_to_http

## 背景

主站服务（DY.Stock.Api）域名由 `stockapi.stplan.cn` 迁移至 `stockapi.jaspil.cn`（`STOCK_BASE_URL` 环境变量已指向新域名）。dev_db_to_http 分支的 db-to-http 数据层已把绝大多数主站 HTTP 收口进 `app/remote_api`（唯一 HTTP 出口），但仍有两个散点绕过它、且各自硬编码老域名：

| 散点 | 用途 | 收口前问题 |
| --- | --- | --- |
| `app/utils/db_stock_api.py` `StockAPIClient` | C 系任务结果回推 `StockParamResult/AddOrModify` | 独立 requests 客户端，默认值硬编码 `http://stockapi.stplan.cn`，`STOCK_BASE_URL` 完全不生效 |
| `app/utils/proxy_manager.py` `SmartProxyManager` | 东财行情代理池 `StockDic/GetProxyListByOne` | 构造参数默认值硬编码 `http://stockapi.stplan.cn/`，同样绕过统一配置 |

即：即使 `STOCK_BASE_URL` 配了新域名，这两条链路仍然打老域名。

## 改动

### 1. 新增两个 remote_api 控制器

- `app/remote_api/controllers/stock_param_result.py`：`StockParamResultApi.add_or_modify(payload)` → `POST /api/StockParamResult/AddOrModify`
- `app/remote_api/controllers/stock_dic.py`：`StockDicApi.get_proxy_list_by_one(payload)` → `POST /api/StockDic/GetProxyListByOne`

均按控制器一文件约定挂入 `controllers/__init__.py::bind_controllers`（`client.stock_param_result` / `client.stock_dic`）。

### 2. 消费方改道统一出口

- `app/services/google_sheet_tasks/base.py`：删除 `self.api_client = StockAPIClient()`，`send_stock_param_result_data()` 改调模块级单例 `stock_api.stock_param_result.add_or_modify(payload)`。重试装饰器（3 次退避）与异常日志路径不变；远端统一信封 `ret_code != 200` 时由 remote_api 抛 `RemoteApiOperationError`（比旧客户端"HTTP 200 即成功"更严格，与本分支数据层语义一致）。
- `app/utils/proxy_manager.py`：`_get_proxy()` 改调 `stock_api.stock_dic.get_proxy_list_by_one()`（返回值即解包后的 `ret_obj`），删除 `base_url` 构造参数与内联 URL；池化/脱敏逻辑不动。远端未配置（`STOCK_BASE_URL` 为空）时抛 `RemoteApiConfigError`，由 dfcf_api 既有异常路径兜底。
- **删除** `app/utils/db_stock_api.py`（全库唯一消费方已改道，无残留引用）。

至此主站 HTTP 全部收敛：数据层仓储 / K线库读写（KlineService）/ 结果回推（base.py）/ 代理池（proxy_manager）/ 身份校验（sys_user 控制器）统一经 `app/remote_api`，基地址唯一来源 `STOCK_BASE_URL`，发请求前校验仅接受 http/https。

### 3. 老域名清理

- `app/config.py`：`SSO_MAIN_VERIFY_URL` 类属性默认值与 `init_app()` 环境变量兜底值改为 `https://stockapi.jaspil.cn/api/SysUser/GetUserInfo`，并留域名迁移注释。
- `.env.example`：`STOCK_BASE_URL` 改为 `https://stockapi.jaspil.cn`，注释改为 remote_api 语义（留空 = 远程数据访问不可用）。
- `app/remote_api/controllers/*.py`：19 个控制器 docstring 内 curl 示例域名批量替换为新域名（纯文档，无行为变化）。
- 保留两处 stplan 字样：`config.py` 的迁移注释本身；`token_identity_service.py` 文档里的主 Web 站点域名 `stock.stplan.cn`（主 Web 域名，非 API 域名）。

### 4. 测试

- `tests/unit/test_proxy_manager.py` 重写：桩 `stock_api.stock_dic` 替身，断言 `ret_obj` 解包与代理 URL 拼装。
- 结果回推无独立单测（原 StockAPIClient 也没有），由既有 C 系集成链路覆盖 `send_stock_param_result_data`。

## 部署注意

- 生产 `.env` 需确认 `STOCK_BASE_URL=https://stockapi.jaspil.cn`（或 `http://`，remote_api 仅校验 scheme 前缀）。
- `SSO_MAIN_VERIFY_URL` 如环境变量有显式配置，需同步改为新域名；未显式配置时自动使用新默认值。
