## 2. P0：admin 族手机端侧边栏（28 页）

### 2.1 根因

28 个 admin 族模板外壳为 `<nav class="col-md-3 col-lg-2 d-md-block sidebar collapse">`：Bootstrap `.collapse` 在 `<768px` 为 `display:none`，而全站没有任何指向它的触发器——手机端零导航（无法跳转、退出登录按钮在侧栏内也不可达）。且 `sidebar.css` 无任何 `<768px` 规则，强行显示会以 `min-height:100vh` 静态块占满首屏。

### 2.2 方案（Offcanvas 抽屉，审查报告 §3.3 方案 A）

- `navbar.js` 渲染时将外壳类整组替换为 `offcanvas offcanvas-start sidebar`（+ `id=templateSidebar`、`tabindex=-1`），并注入移动端顶栏（`d-md-none sticky-top`：汉堡按钮 `data-bs-toggle="offcanvas"` + 品牌区 + 用户下拉含切主题/退出登录）。顶栏插在 `.container-fluid` 之前（`closest('.container-fluid')` 兜底挂载点本身），保证 sticky 定位与全宽。
- 侧栏面板内顶部加 `btn-close d-md-none` 关闭按钮。
- `sidebar.css`：
  - `<768px`：`--bs-offcanvas-width: min(82vw, 20rem)`；
  - `≥768px`：`.sidebar.offcanvas` 强制 `visibility: visible; transform: none; transition: none; position: fixed; width: 25% / 16.6667%`，完全复现原桌面固定侧栏，`.main-content` 外边距规则不变。

### 2.3 关键约束与说明

- **auth 绑定属性重复是安全的（用户名/退出登录）**：顶栏与侧栏各有一套 `data-template-auth-*`，`template-auth.js` 用 `querySelectorAll` 批量填充用户名/头像/权限显隐，退出登录在 `loadNav()` 之后绑定，均能覆盖晚渲染的顶栏。
- **主题触发器需委托绑定（审查后修复）**：原 `bindThemeToggles` 逐节点绑定且在 `bootstrapProtectedPage` 首个 await 之前同步执行，早于 navbar.js 渲染，侧栏/移动端顶栏新注入的 `data-template-theme-trigger` 永远绑不上（点击无响应）。已改为 document 级事件委托 + `loadNav()` 后重跑一次 `applyTheme` 同步图标初始态，见 `docs/model_update/2026-09-29-审查修复.md`。
- **渲染等价红线的解除**：navbar.js 头部注释"渲染产物与原基座逐字节等价"约束静态化迁移期；本次为行为升级，已在文件头注释登记为 D7 修订（沿用 D6 修订先例）。
- **模板零改动覆盖 28 页**：外壳类由 navbar.js 渲染期覆写。注意模板内静态 `sidebar collapse` 类仅在 navbar.js 正常执行时被替换为 offcanvas 形态；JS 加载失败时 `sidebar.css` 的 ≥768px 固定侧栏规则（选择器含 `.offcanvas`）不命中，桌面布局不完整——该失败模式下鉴权/菜单本就不可用，不作为兜底承诺。
- admin-shell.js（子菜单折叠记忆）不涉及外壳显隐，无需改动。
- 桌面端（≥768px）观感与改动前一致（已实测 768/1280 截图比对）。

## 3. P1 修复

### 3.1 卡片头部可换行（12 个模板，24 处）

`card-header d-flex justify-content-between align-items-center` → 追加 `flex-wrap gap-2`。C 系列详情页头部外层 `btn-group`（停止/重启/检查状态/返回首页）改为 `d-flex flex-wrap gap-2`，按钮整颗换行不压缩文字。

### 3.2 C 系列详情键值行长值断行（4 个详情 CSS）

`.col-4 + .col-8 { min-width: 0; overflow-wrap: anywhere; }`——任务名/UUID 等长值在手机 2/3 宽度内可断行，不溢出卡片。

### 3.3 回测结果页工具栏折行（2 个模板）

`details-card` 头部外层 `d-flex justify-content-between align-items-center` 与内层 `d-flex gap-2` 各加 `flex-wrap gap-2`——修复手机端按钮文字竖排挤压。
