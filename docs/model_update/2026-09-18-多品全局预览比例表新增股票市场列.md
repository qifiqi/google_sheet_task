# 修改文档：多品全局预览「比例设置」表新增「股票/市场」列

- 日期：2026-09-18
- 分支：dev_vue
- 范围：多产品回测全局预览页（`/backtest-multi-product/global-preview/<task_id>`）的「比例设置」表
- 性质：展示补字段（前后端接口零改动），**不修改数据库 schema/迁移/数据**

## 背景

比例设置表此前只有「产品 / 比例 / 状态」三列，产品列展示的是产品名（如
「生物科技指数ETF-iShares」）。任务产品较多（截图场景 11 个）时，产品名相近或很长，
看图核对"这行到底配的是哪只标的"很吃力。

任务详情页的「任务输入参数」表已有「股票/市场」列（
`static/js/pages/backtest_multi_product_detail.js`、`frontend/src/views/backtest-multi/Detail.vue`），
展示为 `IBB.US / en`。本次把同一列按同一格式补到全局预览的比例设置表，两个页面口径一致。

## 改动

| 文件 | 改动 |
|---|---|
| `templates/backtest_multi_product/global_preview.html` | 比例设置表 `<thead>` 在「产品」后插入 `<th>股票/市场</th>`（列顺序：产品 / 股票/市场 / 比例 / 状态） |
| `static/js/pages/backtest_multi_product_global_preview.js` | `renderRatios()` 每行插入 `<td class="ratio-code-cell">${stock_code} / ${market_type}</td>`，缺字段回落 `-`，值经 `escapeHtml` |
| `static/css/pages/backtest_multi_product_global_preview.css` | 新增 `.ratio-list-table .ratio-code-cell { white-space: nowrap; }`，避免「代码 / 市场」在窄列下换行 |
| `frontend/src/views/backtest-multi/GlobalPreview.vue` | Vue 版同表补 `<el-table-column label="股票/市场">`，`ratioRows` 增加 `stockMarket: \`${stock_code || '-'} / ${market_type || '-'}\``（与 `Detail.vue` 的 `stockMarket` 逐字一致） |

数据来源无需改动：页面 `previewPayload.products` 就是
`build_multi_product_global_preview_payload` 里 `config["products"]`（经
`normalize_multi_product_config` 归一），本就含 `stock_code`（含市场后缀，如 `IBB.US`）
与 `market_type`（`en`/`cn`/`hk` …）。

## 口径

- 展示格式 `股票代码 / 市场代码`，与任务详情页「股票/市场」列完全一致；不在前端做
  市场代码 → 中文名的翻译（详情页也不翻译，避免两页口径分叉）。
- 产品名为空时仍按原逻辑回落到 `stock_code`；`stock_code`/`market_type` 缺失时该列显示 `-`。
- 仅展示，不参与比例校验与导出计算。

## 兼容性

- 接口与 payload 结构零变化，`ratio-input` 的 DOM 结构与 `data-index` 未动，
  比例输入、合计、计算预览、保存比例、导出等既有交互不受影响。
- 未改 Excel/收益序列导出与 Word 报告（各自列定义独立）。

  `XBI.US / en` 正常输出，缺字段行输出 `- / -`，名称回落与 HTML 转义保持原行为。
