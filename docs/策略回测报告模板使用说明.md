# 策略回测报告模板使用说明

## 文件职责

- `app/services/strategy_backtest_report_template.py`：读取 JSON 并生成 DOCX。
- `app/services/strategy_backtest_report_charts.py`：生成报告使用的图表 PNG。
- `app/services/report_templates/strategy_backtest_report.json`：报告结构、样式、字段和校验规则。

业务侧只负责计算指标并构造 `report_data`；DOCX 排版不应写入 `xpl_service.py`。

## 权重分配规则

所有报告都会显示“权重分配”表，列固定为：`股票代码`、`股票名`、`权重`。

| 报告类型 | 产品数量 | 权重规则 |
| --- | --- | --- |
| `RPT-S` | 单产品 | 必须只有一行，权重为 `100.00%` |
| `RPT-M` | 多产品 | 可传入多行，每行表示一个产品及其权重 |

## Word 接口收益来源

`POST /api/exports/backtest-reports/word` 统一接收累计收益率（不是单日收益率）：

- `RPT-S`：三选一传入根层 `returns`、`task_id`（多个任务结果时加 `return_series_id`），或 `google_sheet_url` / `spreadsheet_id` 加 `google_sheet_name`。v2 的 JSON 与 Google Sheet 均使用此类型。
- `RPT-M`：每个 `products[]` 独立三选一指定上述收益来源，并传 `weight` 或 `ratio`；比例总和必须为 `1` 或 `100%`。服务会将各产品累计收益先换算为单日收益，按比例合成指数与策略，再恢复为组合累计收益。

## 构造报告数据

```python
from tests.fixtures.strategy_backtest_report_demo import build_demo_report_data
from app.services.strategy_backtest_report_template import (
    generate_strategy_backtest_report,
)

# 单产品报告：默认已有一条 100.00% 的权重记录。
report_data = build_demo_report_data("RPT-S")
report_data["weight_allocation"] = {
    "columns": ["股票代码", "股票名", "权重"],
    "rows": [["600519", "贵州茅台", "100.00%"]],
}

# xpl 计算完指标和图表后，填充 sections、charts、conclusion 等字段。
generate_strategy_backtest_report(report_data, "downloads/策略回测报告.docx")
```

```python
# 多产品报告。
report_data = build_demo_report_data("RPT-M")
report_data["weight_allocation"] = {
    "columns": ["股票代码", "股票名", "权重"],
    "rows": [
        ["600519", "贵州茅台", "35.00%"],
        ["000858", "五粮液", "30.00%"],
        ["300750", "宁德时代", "35.00%"],
    ],
}
```

## 仅修改 JSON 的场景

修改 `app/services/report_templates/strategy_backtest_report.json` 即可完成以下调整：

- `metadata_fields`：增删或重命名报告基本信息。
- `blocks`：调整章节顺序，新增标题、文字、表格或条件区块。
- `styles`：修改字体、颜色、页边距、表格和图表尺寸。
- `validation`：调整报告类型、必填字段和权重表校验规则。

## 跨页表格

模板默认会将每张表的首行设置为 Word 的重复标题行。表格跨页时，后一页会自动重复显示表头；同时，单个表格行不会被拆分到两页，章节标题也会和其后的表格保持相邻。

对应配置位于 JSON 的 `styles.table` 和 `styles.headings`：

```json
{
  "repeat_header_row": true,
  "allow_row_break_across_pages": false
}
```

如果希望允许某一行特别长的表格内容跨页，可将 `allow_row_break_across_pages` 改为 `true`。

新增的区块类型或新的 DOCX 渲染能力，才需要修改 Python 渲染器。
