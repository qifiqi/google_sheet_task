# 策略回测 Word 导出说明

本文说明策略回测报告接口与通用 Word JSON 导出协议。

## 入口

- 接口：`POST /api/exports/backtest-reports/word`（`app/routes/export_api.py`）
- 服务链：`StrategyBacktestReportRequestDTO.from_payload` → `StrategyBacktestReportService.generate_word()` → Matplotlib 图表（字体资源位于 `static/fonts/`）→ `generate_word_document()`
- 通用渲染器：`app/services/word_export_template.py`

## 请求体要点（`app/dto/strategy_backtest_report.py`）

| 字段 | 说明 |
|---|---|
| `report_type` | `RPT-S`：单产品（含 V2 回测结果页）；`RPT-M`：多产品回测。 |
| `title` / `filename` | 报告标题与下载文件名。 |
| 单品收益来源 | `returns`、`task_id`（可选 `return_series_id`）或 Google Sheet（`spreadsheet_id` / `google_sheet_url`），三选一。 |
| `products` | 仅 `RPT-M` 使用；每个产品独立选择收益来源并提供权重。 |
| `metadata` / `runtime_params` | 展示元数据及性能分析运行参数。 |

报告编号由服务端生成：单品为 `RPT-S-YYYYMMDD`，多品为 `RPT-M-YYYYMMDD`。多品报告会先将各产品累计收益转日收益、按权重合成，再还原为组合累计收益。

## 通用 Word JSON 协议

渲染器只接受以下顶层结构，不识别任何回测专用模板字段：

```json
{
  "title": "文档标题",
  "footer": "页脚文本",
  "blocks": [
    {"type": "metadata", "items": [{"label": "报告编号", "value": "RPT-S-20260821"}]},
    {"type": "heading", "text": "一、标题", "level": 1},
    {"type": "paragraph", "text": "正文"},
    {"type": "bullet_list", "items": ["项目一", "项目二"]},
    {"type": "table", "title": "表标题", "columns": ["列一"], "rows": [["值一"]]},
    {"type": "image", "title": "图表标题", "path": "chart.png", "caption": "图注"}
  ]
}
```

支持的 `blocks.type` 仅为：`metadata`、`heading`、`paragraph`、`bullet_list`、`table`、`image`。表格每一行必须与 `columns` 列数一致；空表只输出表头。

## 统一样式

- 页面：Letter，左右边距 1.25 英寸，正文字体统一为微软雅黑。
- 标题：22pt；一级、二级、三级标题分别为 15pt、12pt、11pt。
- 表格：蓝色表头、隔行底色、首行跨页重复、行内容不跨页拆分；全部单元格水平及垂直居中。
- 图表：6 英寸宽、居中题注；页脚居中显示 `footer`，未传时显示 `title`。

## 回测报告如何映射

`StrategyBacktestReportService._build_report_data()` 将收益类、风险类、月/日分布、超额收益、极端行情和资金曲线等表格，按顺序扁平映射成 `blocks`。图表、指标计算说明和结论也以相同协议追加到 `blocks`，因此 `word_export_template.py` 不包含任何回测指标或业务分支。

完整演示 JSON 位于 `tests/fixtures/strategy_backtest_report_demo.py::build_demo_report_data()`；本地传入三列日期、指数累计收益、策略累计收益进行完整链路验证可调用 `export_local_word_report()`。
