## 二、处理了什么

### 1. 指标字段统一（`metrics.py` 仅改输出命名，公式零改动）

- `sotino_ratio` → `sortino_ratio`（含嵌套键、月/周字段、`calculate_sortino_ratio` 函数名）
- `excess_sharp` → `excess_sharpe`；`excess_of_promissory_note` → `excess_sortino`
- 直接输出 `excess_cumulative_return`（原 `cumulative_excess`）和 `excess_nav`（超额净值序列末日值）
- 消费者全链路同步：facade、C3/C4/C5/C7、backtest_training、多品预览/详情、Word、CSV 导出、model_summary、12 个模板、正式测试；新链路无旧字段 fallback

### 2. 统一 V1 门面与结果对象（新增 `facade.py`）

- `calculate_v1_metrics()` 成为所有双收益指标的唯一计算入口；C 系列（经 `get_return_analysis_v1`）、backtest_training、多品组合/加权、Word、V2 页面全部经它进入 `_calculate_metrics_v1`
- `MetricsV1Result` 携带 `schema_version`、完整 `metrics`、`canonical_metrics`（benchmark/strategy/relative/distributions 分组投影）
- `to_json_dict(include_series=False)` 成为统一持久化序列化出口（生产调用 2 处）

### 3. 多品组合算法统一（新增 `portfolio_combiner.py`）

- 唯一组合器 `combine_product_returns()`：默认且唯一算法为"累计收益 → 日收益 → 按比例加权 → 复利累计"
- 旧版累计收益直接加权（legacy）算法**停用并按仓库约定注释保留**（`normalize_weighting_mode` 固定返回 daily_compound；多品服务 `_scale_return_date` 等残留注释停用）
- 修复日期边界 bug：先截取共同日期交集、再从共同区间起点还原日收益，不再引用区间外净值
- 比例解析统一入口 `normalize_weight`：`30` / `30%` / `0.3` 等价（30%）；比例总和不足 100% 保留现金语义，不强制归一化
- 多品任务配置主字段切换为 `weighting_mode`（执行参数、预览缓存键、Word payload、详情路由、创建页同步；创建页旧开关注释）

### 4. 存储契约统一

- 新写入统一为 `metrics_payload = {schema_version, metrics, canonical_metrics}`：
  - C3/C4/C5/C7 不再持久化重复的 `analyze_result` 全量字典（`flat_result` 保留，它是导出/汇总服务的读取契约）
  - backtest_training 的 `calculate_metrics` 键改为 `metrics_payload`
  - 多品比例后指标写入 `metrics_payload.weighted_metrics`（旧缓存载荷回退兄弟键）
- 读取方全部接通（训练 API 三处、多品 `_extract_result_core`/detail 路由、model_summary、多品预览），统一走 `extract_core_metrics` / `extract_core_weighted_metrics` 共享助手

### 5. 历史数据读取兼容（新增 `historical_metrics.py`，全部带 TODO）

新链路不写旧字段；**读取数据库旧载荷**时升级旧键名（`sotino→sortino`、`cumulative_excess→excess_cumulative_return`、`excess_net→excess_nav` 等）。接入点：
- `backtest_training_api_service._extract_task_result_payload`
- `backtest_multi_product_service._extract_result_core`
- `model_summary_service._extract_backtest`
- `performance_analysis/exporter.format_export_file_data`
- 多品历史 config 的旧布尔字段回退（`normalize_multi_product_config`）

### 6. Word 报告去重（`strategy_backtest_report_service.py`）

八个章节全部改为直接消费 V1 结果，删除了自行实现的 `_daily_returns`、`_monthly_returns`、`_distribution`、`_matched_pairs`、`_count_below`、`_skew`、`_kurtosis`、`_ratio_by_abs`、`_compound_return`、`_consecutive_changes` 等重复派生：

- 累计回报/超额取 V1 字段；滚动收益消费 V1 滚动序列（含不足 5 年 reason 占位）
- 月度/日度统计与分布、超额统计/分布/滚动、极端行情、资金曲线全部取 V1 字段与分布列表
- 仅保留对 V1 数值列表的展示级统计（中位数、月超额标准差）与从 V1 净值列读取创新高
