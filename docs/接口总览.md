# 接口总览

蓝图注册在 `app/routes/__init__.py::register_blueprints`。统一响应格式 `{"status","code","message","data"}`（`app/utils/api_response.py`）。除标注"页面"外均为 JSON API；鉴权见 [登录与鉴权指南.md](登录与鉴权指南.md)。

URL 命名约定（2026-09 收敛后）：路径段一律 kebab-case；JSON API 一律 `/api/<域>/**`（管理端 `/api/admin`、回测子域 `/api/backtest-training` 等）；资源集合用复数；批量动作统一 `batch-<动词>`（batch-create / batch-export）；页面蓝图前缀在蓝图定义处、API 蓝图前缀统一在注册处传入。

## /api 前缀

### 任务（task_api.py）

`GET/POST /api/tasks`、`POST /api/tasks/batch-create`（C31 批量）、`GET/PUT/DELETE /api/tasks/<task_id>`、`PUT /api/tasks/<task_id>/config`、`POST /cancel`、`GET /logs`、`GET /status-check`、`GET /stop-confirmation`、`POST /restart`、`POST /create-restart`

### 鉴权（auth_api.py + sso.py）

`POST /api/auth/login`、`/refresh`、`GET /me`、`POST /logout`、`PUT /password`；`POST /api/auth/sso/exchange`（主服务免登换票）；用户/角色/权限管理 `/api/admin/users|roles|permissions`

### 管理端（admin_api.py + scheduler_api.py）

统一 `/api/admin/*`：`GET /api/admin/dashboard/overview`、`GET /api/admin/model-summary`（`POST /rebuild`、`GET /rebuild/status`）、`GET /api/admin/word-export-cache`（`POST /clear`）、`GET /api/admin/tasks/<task_id>/runtime-detail`；调度 `/api/admin/scheduler/*`（stats、tasks CRUD、`POST .../<id>/toggle`、`POST .../<id>/run`）

### 配置与导航（config_api.py + navigation_api.py + logs_api.py + meta_api.py）

`GET/POST /api/config`、`GET /api/config/validate`、`GET /api/system-configs`、`PUT /api/system-configs/<key>`；`/api/navigation-menu-items` CRUD；`GET /api/logs`、`/api/logs/latest`；`GET /api/meta/versions|enums|nav`

### 模板与结果（template_api.py + result_api.py）

`/api/templates` CRUD；`GET /api/results`、`GET/DELETE /api/results/<int:result_id>`、`GET /api/tasks/<task_id>/results`

### Google Sheet 资源（google_sheet_api.py）

`/api/google-sheets`（注册表 CRUD）、`POST /api/google-sheets/worksheets`（工作表探测）、`/api/google-sheet-tokens`（Token 池：GET 列表、`GET/PUT/DELETE /<int:token_id>`、`POST /import`、`POST /reconcile`）

### 股票与绩效分析

`GET /api/search-stocks`、`GET /api/klines`（stock_api.py，K线查询：data_source 可选 dfcf/qq/akshare/yahoo/tdx/database，kline_type 支持日/周/月/分钟，分钟仅 dfcf/qq；供 K线页面表格与 klinecharts 图表使用）；绩效分析（performance_analysis_api.py）：`POST /api/performance-analysis/analyze`（统一分析入口，载荷按来源分流：`data` 粘贴文本 / `spreadsheet_id` Sheet 链接 / `result_id` 任务结果 ID）、`GET /api/performance-analysis/weight-combination/products`、`POST /api/performance-analysis/weight-combination`（流式 NDJSON）

### 回测子域（backtest_api.py + global_preview_api.py）

- 单品 `/api/backtest-training/*`：`POST /import-excel`、`GET /task-result/<int:id>`、`GET /task-result/<int:id>/export-preview`、`GET /task-results/<task_id>`、`GET /task-summary/<task_id>`、`GET /global-preview/<task_id>`
- 多品 `/api/backtest-multi-product/*`：同构端点 + `POST /global-preview/<task_id>/calculate-ratios`、`PUT /global-preview/<task_id>/ratios`、`POST /global-preview/<task_id>/return-series`
- 全局预览 `/api/global-preview/*`：`GET /tasks/<task_id>`、`POST /tasks/<task_id>/preview-group`

## /api/exports（export_api.py）

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/exports/tasks/<task_id>` | GET | 任务结果导出 |
| `/api/exports/tasks/<task_id>/stocks` | GET | 按股票导出 |
| `/api/exports/tasks/batch-export` | POST | 批量导出（ZIP 流式） |
| `/api/exports/global-previews/<task_id>` | GET | 全局预览导出 |
| `/api/exports/global-previews/<task_id>/stocks` | GET | 预览按股票导出 |
| `/api/exports/global-previews/batch-export` | POST | 预览批量导出 |
| `/api/exports/backtest-results/<int:result_id>` | GET | 回测结果导出 |
| `/api/exports/performance-analysis` | POST | 绩效分析导出 |
| `/api/exports/backtest-reports/word` | POST | Word 回测报告（见 [策略回测报告模板使用说明.md](策略回测报告模板使用说明.md)） |
| `/api/exports/model-summary` | GET | 单模型汇总导出 |

约束：仅 `completed` 任务可导出；`ratios` 查询参数用于多品比例。实现见 `app/services/export_service.py` / `export_file_service.py`。

## 参数约定

- C31 批量创建 payload：`{config: {base_task_name, sheets[], stock_codes[], parameters[][]}}`，市场值传英文 `cn`/`en`，日期字段统一 `end_date`。
- 回测任务 `market_type` 规范为 `cn`/`en`。
- Word 报告请求结构见 DTO `app/dto/strategy_backtest_report.py`。
