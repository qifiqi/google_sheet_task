# 接口总览

蓝图注册在 `app/routes/__init__.py::register_blueprints`。统一响应格式 `{"code", "data", "message"}`（`app/utils/api_response.py`）。除标注"页面"外均为 JSON API；鉴权见 [登录与鉴权指南.md](登录与鉴权指南.md)。

## 页面蓝图

| 蓝图 | 前缀 | 内容 |
|---|---|---|
| auth_pages_bp | `/login` | 登录页 |
| admin_bp | `/admin` | 后台页面（dashboard/tasks/config/navigation/logs/templates/results/model-summary/eastmoney-kline/google-sheets/scheduler/users/roles） |
| google_sheet_bp | `/google-sheet` | C 系列页面：`/`、`/create`、`/merge-export`、`/detail`（version=c3/c4/c5/c7/c31 由 query 参数区分） |
| backtest_training_bp | `/backtest-training`（legacy `/backtest`） | 单品回测页面 |
| backtest_multi_product_bp | `/backtest-multi-product`（legacy `/backtest-multi`） | 多品回测页面 |
| global_preview_bp | `/global-preview` | C7.0.3 全局预览页 |
| xpl_bp | `/xpl` | 收益绩效分析（`/analyze`、`/v1`、`/v2`） |
| yule_bp | `/yule` | 娱乐/数据小工具页 |
| eastmoney_kline_bp | `/eastmoney-kline` | K 线代理页面 |

## /api 前缀

### 任务（task_api.py）

`GET/POST /api/tasks`、`POST /api/tasks/batch-create`（C31 批量）、`GET/PUT/DELETE /api/tasks/<id>`、`/api/tasks/<id>/config`、`/cancel`、`/logs`、`/results`、`/status-check`、`/stop-confirmation`、`/restart`、`/create-restart`、`/api/system-logs`

### 鉴权（auth_api.py）

`POST /api/auth/login`、`/refresh`、`GET /me`、`/logout`、`POST /password`；用户/角色/权限管理 `/api/admin/users|roles|permissions`

### 管理（admin.py，部分挂 /admin/api）

`/api/dashboard/overview`、`/api/model-summary`（GET/rebuild）、`/api/tasks/<id>/runtime-detail`、导航/配置/日志管理页面 API

### 配置（config_api.py）

`/api/config`、`/api/system-configs`、`/api/navigation-menu-items`、`/api/logs`、`/api/config/validate`

### 模板与结果（template_api.py）

`/api/templates`、`/api/results`

### Google Sheet 资源（google_sheet_api.py）

`/api/google-sheets`（注册表 CRUD）、`/api/google-sheet/worksheets`、`/api/google-sheet-tokens`（Token 池）、`/api/google-sheet-tokens/import`

### 回测（backtest_training.py / backtest_multi_product.py）

- 单品：`/api/import-excel`、`/api/task-results/<id>`、`/api/task-summary/<id>`、`/api/global-preview/<id>`、`search_stocks`（股票搜索）
- 多品：`calculate-ratios`、`ratios` PUT、结果/预览等同构端点
- 全局预览：`/api/tasks/<id>/preview-group`（global_preview.py）

### 其它

- database_api.py：`/api/database/status|vacuum|suggestions`
- stock_api.py：`/api/search-stocks`
- meta_api.py：`/api/meta/versions`、`/api/meta/enums`、`/api/meta/nav`
- scheduler_api.py：`/api/admin/scheduler/*`（stats、tasks CRUD、toggle、run、status）

## /api/exports（export_api.py）

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/exports/tasks/<id>` | GET | 任务结果导出 |
| `/api/exports/tasks/<id>/stocks` | GET | 按股票导出 |
| `/api/exports/tasks/batch` | POST | 批量导出（ZIP 流式） |
| `/api/exports/global-previews/<id>` | GET | 全局预览导出 |
| `/api/exports/global-previews/<id>/stocks` | GET | 预览按股票导出 |
| `/api/exports/global-previews/batch` | POST | 预览批量导出 |
| `/api/exports/backtest-results/<id>` | GET | 回测结果导出 |
| `/api/exports/xpl` | POST | XPL 分析导出 |
| `/api/exports/backtest-reports/word` | POST | Word 回测报告（见 [策略回测报告模板使用说明.md](策略回测报告模板使用说明.md)） |
| `/api/exports/model-summary` | GET | 单模型汇总导出 |

约束：仅 `completed` 任务可导出；`ratios` 查询参数用于多品比例。实现见 `app/services/export_service.py` / `export_file_service.py`。

## 参数约定

- C31 批量创建 payload：`{config: {base_task_name, sheets[], stock_codes[], parameters[][]}}`，市场值传英文 `cn`/`en`，日期字段统一 `end_date`。
- 回测任务 `market_type` 规范为 `cn`/`en`。
- Word 报告请求结构见 DTO `app/dto/strategy_backtest_report.py`。
