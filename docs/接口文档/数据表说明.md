# 当前模型 CRUD 清单

## 约定

后续新增业务 `db.Model` 时，必须在本文件新增一行，写明对应数据库表、业务用途及需要的 HTTP CRUD 操作。除运行过程自动维护的数据外，所有业务配置和管理数据都应通过 HTTP CRUD 管理，不直接改数据库。

本文中的 CRUD 含义：`C` 创建、`R` 列表/详情查询、`U` 更新、`D` 删除。`受控` 表示不能直接改表数据，必须调用已有业务操作，以维持任务、资源占用和关联数据的一致性。

## 主系统接入对象（不属于本系统业务 CRUD）

用户、角色、权限及其关联表后续会从本系统移除，改为接入主系统。因此它们不纳入本系统后续 CRUD 建设；迁移前现有接口仅作为兼容能力保留，不再新增或扩展本地 CRUD。

| 模型/表 | 当前本地用途 | 后续处理 |
| --- |  | --- |
| `User` / `user` | 用户、登录和角色归属 | 改由主系统提供身份与用户信息；本地仅保留主系统用户标识的引用。 |
| `Role` / `role` | 本地 RBAC 角色 | 改由主系统提供角色信息，不再维护本地角色 CRUD。 |
| `Permission` / `permission` | 本地 RBAC 权限定义 | 改为消费主系统的权限标识或授权结果。 |
| `role_permissions` | 角色与权限关联 | 随本地角色、权限表一并移除。 |
| `user_roles` | 用户与角色关联 | 随本地用户、角色表一并移除。 |


## 具体业务与管理表

| 模型 | 数据库表 | 当前代码用途 | 当前查询条件 | 当前 HTTP 使用情况 | 应使用的 CRUD |
| --- | --- | --- | --- | --- | --- |
| `Task` | `tasks` | C3/C4/C5/C7、回测等任务主记录 | 详情按 `id`；列表按 `task_type`/允许任务类型、`status`、`keyword`（名称/描述/ID）筛选，按 `created_at DESC` 分页；看门狗按近 5 天创建时间、运行中或可重试错误筛选；回测排队按回测任务类型、`pending`、排除已完成任务筛选。 | `task_api.py` 提供创建、查询、删除、取消、重启等业务接口 | 受控 CRUD；创建、更新状态、取消、重启、删除必须经 `TaskManager`，不可直接写运行状态 |
| `TaskTemplate` | `t_param_task_templates` | 可复用任务配置模板 | 详情按 `id`；列表按 `created_at DESC`，可按配置 JSON 内的 `task_type` 在内存过滤。 | `template_api.py` 已提供完整 CRUD | 完整 CRUD |
| `SystemConfig` | `t_param_system_configs` | 系统运行配置 | 单项按唯一 `key`；全量加载或按 `key ASC` 排序列表。 | `config_api.py` 已提供列表和按 key 更新 | 受控 CRUD；应通过配置管理逻辑更新并刷新缓存，删除仅在确认无引用时提供 |
| `NavigationMenuItem` | `t_param_navigation_menu_items` | 后台侧边栏导航 | 单项按 `id`；唯一性校验按 `key`，父级按 `parent_key`；菜单列表按 `parent_key`、`sort_order`、`id` 升序，前端导航另筛选 `is_visible=True`。 | `config_api.py` 已提供完整 CRUD | 完整 CRUD；删除前检查子菜单，变更后同步导航权限 |
| `GoogleSheetToken` | `t_param_google_sheet_tokens` | Google Sheet Token 池 | 详情按 `id`；列表可按 `task_type`，按启用状态、当前占用次数、累计使用次数、名称排序；随机选择按 `is_active=True`、`task_type`，再按占用/使用次数排序；导入去重按 `token_context + task_type`。 | `google_sheet_api.py` 已提供查询、导入、更新、删除 | 受控 CRUD；创建通过导入，更新不得直接改使用计数，删除前检查占用状态 |
| `GoogleSheet` | `t_param_google_sheet` | Google Sheet 注册与占用状态 | 详情按 `id`；列表可按 `table_type`、是否包含停用项、是否可用（未占用或当前任务已占用）筛选，按名称、ID 升序；重复校验按 `spreadsheet_id + registry_scope`，释放占用按 `current_task_id`。 | `google_sheet_api.py` 已提供完整 CRUD | 受控 CRUD；占用状态由任务管理器维护，删除前检查是否正在使用 |
| `ScheduledTask` | `t_param_scheduled_tasks` | 定时任务定义与调度状态 | 详情按 `id`；列表按 `created_at DESC` 分页；调度器加载和统计按 `is_active=True`，默认清理任务去重按 `name + task_function`。 | `scheduler_api.py` 已提供完整 CRUD，并有启停、立即执行等操作 | 受控 CRUD；`is_running`、运行次数和下次执行时间由调度器维护 |
| `StockMetadata` | `t_param_stock_metadata` | 股票代码、市场和搜索元数据 | 查询与去重按 `stock_code + market_type`；命中多条时按 `updated_at DESC, id DESC` 取最新记录。 | 当前无独立管理 CRUD 路由 | 需要 CRUD；创建/更新可由搜索或同步服务写入，管理端至少应支持查询、详情和删除/刷新 |

## 任务产出与运行态表

| 模型 | 数据库表 | 当前代码用途 | 当前查询条件 | 当前 HTTP 使用情况 | 应使用的 CRUD |
| --- | --- | --- | --- | --- | --- |
| `TaskLog` | `task_logs` | 任务执行日志 | 按 `task_id` 查询，按 `timestamp DESC` 取最新或最近 N 条；历史清理按 `timestamp < cutoff_date` 分批。 | 任务/配置接口提供日志查询 | 只读查询；日志由任务服务写入，不提供创建、更新、删除 |
| `TaskResult` | `t_param_task_results` | 每一步任务结果 | 详情按 `id`；任务结果按 `task_id`，按 `step_index ASC, timestamp ASC, id ASC` 分页/排序；最新结果按 `task_id`、`timestamp DESC`；全局结果按可访问 `Task.task_type`，按 `timestamp DESC` 分页；清理按 `timestamp < cutoff_date`。 | `template_api.py`、回测页面接口提供查询和删除 | 受控 CRUD；任务服务创建，前端仅查询和按业务规则删除，不能更新结果内容 |
| `TaskResultReturn` | `t_param_task_results_return` | 任务收益曲线 | 按 `id`（通过 `TaskResult.return_series_id`）或 `task_id` 查询；任务曲线按 `stock_date ASC` 排序。 | 回测页面接口查询使用 | 只读查询；由任务结果生成/清理流程维护 |
| `BacktestProductResultCache` | `t_param_backtest_product_result_cache` | 多品回测同批次结果缓存 | 按唯一组合 `batch_id + cache_key` 查询/去重。 | 当前无独立管理路由 | 不提供通用 CRUD；由回测服务创建、查询和清理，可按批次提供受控清理操作 |
| `BacktestSheetRunLock` | `t_param_backtest_sheet_run_locks` | 回测任务的 Google Sheet 运行锁 | 取得/冲突检查按唯一 `spreadsheet_id`；任务清理按 `task_id`。 | 当前无独立管理路由 | 只读查询或受控释放；锁只能由任务生命周期和故障恢复逻辑创建/删除 |
| `TaskResultSummaryIndex` | `t_param_task_result_summary_index` | 任务结果汇总查询索引 | 索引写入查询按 `task_result_id` 或其批量集合；汇总查询可按 `task_type`、`task_id`、`task_result_id`、股票代码关键字、`market_type`、`period_key`、最优指标下限、结果日期范围、`is_best` 筛选，默认按结果日期、最优指标、ID 降序；重建/清理可按 `task_id`、`task_type`。 | 当前由汇总服务维护 | 只读查询；索引写入、更新和重建只能由汇总服务处理，不提供通用修改/删除 |

`GoogleSheetTableType`、`GoogleSheetTokenTaskType`、`TaskStatus`、`TaskType` 是 Python 枚举，不是数据库表，不需要 CRUD。

## 新增模型时的最小要求

1. 在本文件登记模型与表名，并确定它属于“具体业务与管理表”还是“任务产出与运行态表”。
2. 具体业务与管理表默认需要完整 CRUD；确有例外时，在“应使用的 CRUD”列说明原因。
3. 运行态表默认只读或受控操作，不能通过通用 CRUD 破坏任务执行、资源占用、缓存或锁。
4. 实现接口后，将实际入口文件同步填入“当前 HTTP 使用情况”列。
